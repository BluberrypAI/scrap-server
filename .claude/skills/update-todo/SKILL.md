# update-todo

## 형식

```
| ID | 작업 | 상태 | 담당 | spec | 비고 |
```

| 열 | 규칙 |
| --- | --- |
| ID | `T-<주차><번호 2자리>`. 1주차는 T-001~, 2주차는 T-101~. 한 번 쓴 ID는 재사용하지 않음 |
| 작업 | 한 줄, 동사로 끝나지 않아도 됨. 결과물이 드러나게 씀 |
| 상태 | `대기` `진행` `완료` `보류` 중 하나 |
| 담당 | 역할 이름(api-developer 등) 또는 `사람` |
| spec | docs/specs/ 파일 이름(확장자 제외) 또는 `-` |
| 비고 | 보류 이유, 선행 작업, 확인 필요 사항 |

## 규칙

1. 작업을 시작하면 `진행`, 테스트까지 통과하면 `완료`로 바꿈
2. 막히면 `보류`로 바꾸고 비고에 이유를 씀
3. 작업 중 새로 생긴 할 일은 해당 주차 표에 추가함
4. 완료된 항목은 지우지 않음 (진행 기록으로 남김)
5. 사람이 해야 하는 일(키 발급, 자료 확보)은 담당을 `사람`으로 두고 사용자에게 알림
