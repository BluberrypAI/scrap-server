# 공정 관련 업체 Top5와 B 문의·수락 검증

2026-11-19. 로컬 통합 Docker에서 검사했습니다. 실제 Azure와 카카오 API를 사용했으며, 계정의 사업장 연결·사진의 물량 설명·반입조건·인수·산출물은 합성 시험입니다. 실제 업체에 연락하거나 물량을 보내지 않았습니다.

## 바뀐 기준

SCRAP은 이번 폐기물과 공정에 관련된 업체를 찾아 문의하도록 돕습니다. B가 외부 물량의 수분·순도·가격·허용량을 공개하지 않았다는 이유만으로 후보를 숨기지 않습니다. 실제 사업장의 소재와 수행 공정·제조공장 생산품을 확인하며 판매 목록만 있거나 재질·사업장이 불명확한 자료는 별도 조사로 남깁니다. 명시 취급 제외도 유지합니다.

`process_match`, `process_source`, `process_quote`는 기존 응답에 추가한 필드입니다. `kind=insufficient`라도 공정 관련성이 확인되면 문의 후보가 될 수 있습니다. 구체 투입 형태의 반입 근거 또는 실제 반입 승인으로 승격한 것은 아닙니다. 수신 계정 연결도 별도로 필요합니다.

새 후보의 자동 질문은 0개입니다. A는 사진·상태·중량을 보내고 B와 메시지로 조건을 협의합니다. B는 처리 범위와 반입조건을 확인한 뒤 수락하며, 업체가 직접 요구한 조건부 수락은 유지합니다. 기존 답변 저장 API와 과거 이력은 호환 보존합니다.
