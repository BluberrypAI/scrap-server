# 문진부터 업체 검토까지 연결 점검

> 후속 업데이트: R유형 전달과 과도 보류 2건은 [R코드 통합 검사](r-code-flow-audit-20261116.md)에서 구현·검증했습니다. 이 문서는 그 이전 검사의 기록입니다.

2026-11-16. 대상은 로컬 통합 구성 `web:5178 → server:8000 → diagnosis:8030 / route:8010`입니다. 시험 기업과 물량은 합성 데이터입니다.

## 팀이 제기한 문제

| 문제 | 확인 결과와 수정 |
| --- | --- |

| 기업 실제 위치 등록 | 기업 등록·정보 수정 화면에서 지도 위치를 지정해 저장합니다. 실제 브라우저에서 저장→새로고침→유지를 확인했습니다. A→B는 A, B→C는 현재 보유 기업 B의 좌표를 사용합니다. |

## 현재 플로우

1. 로그인 기업의 문진을 diagnosis가 진행하고, server가 확정 결과·번호·주의사항을 보관합니다.
2. 세부 재질이나 고체 여부가 빠졌으면 필요한 항목만 보충합니다. 액체·위험성 보류를 이 답변으로 덮어쓰지 않습니다.
3. 번호·세부 재질·현재 형태로 PostgreSQL의 공정·사업장 자료를 조회합니다.
4. 사업장 좌표가 확인된 후보 최대 5곳을 직선거리로 먼저 보여 줍니다. 나머지 후보도 목록과 AI 검토에 포함합니다. 도로 거리 순위는 아직 아닙니다.
5. route가 모든 후보의 공개 요약을 검토합니다. 첫 후보 미리보기는 결과·부족 사유를 응답으로 반환하고, 실제 물량 단계의 검토는 server의 인계 기록에 저장합니다. 제품 판매 자료를 폐기물 반입 근거로 승격하지 않습니다.
6. 실제 물량은 중량·상태·사진을 붙여 다시 검토하고 수신 기업이 수락해야 인계합니다. B 처리 후 실제 산출물을 기록해야 다음 업체를 조회합니다.

후보 표시, 공개 근거 확인, 허가 확인, 업체 수락, QR 입고는 서로 다른 상태입니다.

## 공정 자료와 새 연결

현재 참조는 **52개 사업장 / 63개 공정 / 109개 연결**입니다. 109개 중 11개는 역할 추정입니다. 전국 명부 9,604행은 조사 단서이며 이 숫자와 합산하지 않습니다.

## 검사 범위

- 실제 버튼 문진: 18선택지, 일반 분류번호 12개. 현재 엔진의 예상 번호와 일치함을 검사한 것이며 독립 전문가의 법적 정답 검수는 아닙니다.
- 지원 선택지: 15개. 형태 조합 56개 중 후보 53개, 보류 3개(일반 PE 베일 2조합·PS 베일 1조합).
- 실제 유해성 답변 문진 11건은 모두 `review_required`이며 후보로 통과하지 않았습니다.
- PET 두 번호·PE 폐비닐 베일·EPS 부표·철드럼의 실제 문진 5건으로 합성 물량을 등록하고 다시 읽었습니다. 원래 번호·세부 재질·시작 상태가 저장되는 것을 확인했습니다. 이는 업체 수락·QR 입고 완료와 별개의 검사입니다.
- 실제 Edge 브라우저 클릭 검사 **59개 전부 통과**: 형태 56조합·미지원 소재 보류 3개. 고체 확인이 필요한 경우 화면 순서에 따라 먼저 확인하고 재질·형태를 선택했습니다. 로그인은 로컬 개발용 계정이며 API 응답을 모킹하지 않았습니다.
- 공정 직접 HTTP 조회 208회: 활성 소재의 104연결·58공정 도달. 나머지 5연결·5공정은 이 문진 범위 밖 종이입니다.
- server: SQLite 454개, 별도 PostgreSQL 17 시험 DB 454개 통과. 실제 통합 DB의 PostgreSQL 16 볼륨은 변경하지 않았습니다.
- web: 48개 테스트와 production build 통과. 큰 번들 경고는 남습니다.
- route: 540개·subtest 24개 통과, 환경 의존 72개 제외. 후보별 실제 Azure 재검토는 이 단위 테스트와 별도입니다.

## 실제 Azure 검토 결과

후보가 있는 **53개 형태 조합의 294회 검토**를 실행했습니다. 고유 공정·사업장 연결은 98개입니다. 각 조합에서 조회된 후보 키와 AI 응답 키가 모두 일치했습니다.

| 결과 | 횟수 | 의미 |
| --- | ---: | --- |
| 공개 근거 확인 | 50 | 이 형태·공정에 적용할 공개 근거 확인. 실제 허가·이번 물량 반입 승인 아님 |
| 근거 부족 | 244 | 후보는 표시하되 부족 사유와 다음 확인 자료를 함께 표시 |
| 호출 오류·검토 누락 | 0 | 필요한 조합만 재시도한 **최종 결과**. 첫 시도 성공률은 아님 |

처음에는 Azure 429·시간 초과, 프록시 504, 장시간 시험 스크립트의 쿠키 만료가 있었습니다. 대기·재시도 범위를 수정하고 실패한 조합을 다시 실행했습니다. HTTP 401만 로그인 갱신 후 재시도하며 모호한 시간 초과를 자동 재전송하지 않습니다. 중간 결과 파일은 완전한 호출 이력이 아니므로 총 호출 수·비용·첫 시도 성공률을 이 표에서 계산하면 안 됩니다.

기존 252회 중 남은 242회의 **첫 사유**는 투입 형태 170, 사업장 범위 30, 재질 18, 생산품 소개만 있음 12, AI 전달 가능한 적용 근거 없음 12입니다. 한 응답에 여러 부족 사유가 있을 수 있으며, 첫 사유가 반드시 가장 심각한 문제라는 뜻은 아닙니다. 중복 집계와 사업장별 내용은 [상세 보고서](registry-screen/intake-evidence-gaps-20261116.md)에 있습니다.

전체 부족 244회에는 위 242회 외에 넷스파 부산 PA6 어망, 대한제강 녹산 철스크랩 각 1회도 포함됩니다. 이번 모델 응답은 사업장 범위를 부족 사유로 분류했습니다. 관련 사업장·공정 요약은 전달됐으므로 호출 실패나 자료 미전송으로 처리하지 않았습니다. 원문 대비 보수적 오판 가능성도 별도 평가해야 합니다. 이 상태 횟수는 모델의 **정확도 점수**가 아닙니다.

일반 PET `51-03-01`은 실제 브라우저에서 **업체 공개 근거 AI 검토** 버튼을 다시 눌러 7개 연결 모두 응답·표시를 확인했습니다. 3개는 공개 근거 확인, 4개는 근거 부족이고, 부족 사유도 화면에 표시됩니다. 모든 응답의 `dispatch_approved`는 false입니다. [비식별 AI 검토 요약](ai-review-summary-20261116.json).

실제 문진·형태별 목록은 [JSON 결과](flow-audit-20261116.json)에 있습니다. 이번 테스트는 연결·근거 검토 범위이며 신규 모든 업체와 실제 계약·배송을 한 시험이 아닙니다. 이전 QR 시나리오는 [11/15 통합 기록](full-stack-validation-20261115.md)에서 별도로 확인할 수 있습니다.

## 팀 적용 순서

server #47, route #61, web #46, infra #5 변경을 함께 적용해야 합니다. diagnosis는 이번에 변경하지 않았습니다. develop만 받아서 아직 병합 전인 변경이 빠지면 이전 화면이 나올 수 있습니다.

```bash
# scrap-infra에서 실행. 실행 중인 검토가 끝난 뒤 재빌드합니다.
docker compose up -d --build server route web
docker compose run --rm server-seed
```

브라우저는 **http://localhost:5178**을 사용합니다. 로그인 쿠키 때문에 127.0.0.1과 섞지 않습니다. 기업 데이터 관리에서 실제 사업장 위치를 저장하고, PET 또는 포장재 문진의 기존 번호를 유지한 채 형태를 선택합니다.

PG17 업데이트가 포함된 server 단독 compose를 기존 PG16 데이터 볼륨에 바로 연결하지 마세요. 이번 infra 수정은 DB 버전을 바꾸지 않습니다. 별도 백업·이관은 팀 작업입니다.

## 재현 도구

`scripts/audit_diagnosis_routes.py`로 합성 버튼 문진을 만들고, 그 결과 JSON을 아래에 전달합니다. AI 검토는 실제 Azure 호출이며 팀의 로컬 설정이 필요합니다.

```bash
uv run --with playwright --project backend python scripts/audit_route_browser.py --input <문진결과.json> --output <브라우저결과.json>
uv run --project backend python scripts/audit_case_reviews.py --input <문진결과.json> --output <AI결과.json> --all-forms --concurrency 1 --delay 10
```

원본 실행 자료·브라우저 스크린샷은 로컬 output/verification/flow-audit-20261116에 보관합니다. 저장소에는 합성 사례의 비식별 요약·공개 사업장 키·검토 범주만 올립니다. 에이전트 문서 영향 점검: 역할·공통 규칙 변경 없음.
