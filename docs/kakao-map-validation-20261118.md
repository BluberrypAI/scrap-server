# 카카오 지도·주소·길찾기 연결

2026-11-18 로컬 통합 실행 기준. 운영 배포·푸시는 하지 않았다.

- 회원가입·기업정보 수정의 위치 선택, 공정·업체 후보 지도, 순환자원지도, 인계 지도와 기존 처리 상세 지도에 카카오 SDK를 연결했다.
- 주소 입력 → 카카오 주소 검색 → 결과 선택 → 핀 확인·클릭·드래그 → 기존 기업 좌표 필드로 저장한다. 주소 결과가 없으면 장소 검색을 하고 지역 대표점은 건물 위치로 단정하지 않는다.
- 인계 지도는 직선 대신 도로 좌표를 표시한다. A→B는 A, B→C는 당시 B에서 출발한다. 좌표 누락·조회 실패 시 해당 선을 그리지 않는다. 실제 차량 GPS 이력은 아니다.

## 확인한 결과

Edge A 화면에서 엔피씨 화성공장→독산 화성의 도로를 따라 꺾이는 선을 확인했다. 카카오모빌리티 실호출 HTTP 200·result_code 0, 거리 **6,495m**, 도로 좌표 **164개**다. 지도는 6.5km로 표시한다.

기업정보 수정에서 `경기도 화성시 남양읍 현대기아로 239-11`을 검색하자 `경기 화성시 만세구 남양읍 현대기아로 239-11`이 반환됐고, 선택 시 `37.17144, 126.84479`에 핀이 연결됐다. 저장 버튼으로 서버 기업 정보까지 반영했다. 회원가입도 같은 컴포넌트를 사용한다. 신규 소셜 OAuth 가입은 이번 검증에 포함하지 않았다. 순환자원지도에서도 카카오 바탕지도와 업체 핀 표시를 확인했다.

서버 전체 621개·웹 89개 테스트, Ruff, Docker 서버·웹 빌드 통과. 외부 오류·빈 경로·잘못된 좌표, 참여 기업 권한, B 출발지, 주소/장소 검색을 검사했다.

## 설정과 전송

`scrap-infra/.env`의 `VITE_KAKAO_MAP_APP_KEY`는 JavaScript 키, `KAKAO_MOBILITY_REST_API_KEY`는 서버 REST 키다. 카카오맵 ON과 JavaScript SDK 허용 도메인 등록 후 웹을 다시 빌드한다. 키는 git에 올리지 않는다.

지도 검색에는 주소/장소명, 길찾기에는 두 사업장 좌표를 전송한다. 문진·폐기물 사진·회원 쿠키·QR은 지도 API로 보내지 않는다. 새 `GET /api/v1/workflow/lots/{id}/road-route`는 참여 기업만 조회하며 구간 좌표·거리·시간·상태·제공자를 no-store로 반환한다. 카카오 검색·경로 원문은 업무 DB에 저장하지 않는다.
