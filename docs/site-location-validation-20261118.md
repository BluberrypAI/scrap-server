# 주소 검색과 사업장 위치 등록 검증

2026-11-18, 로컬 Docker 통합 환경에서 검증. 운영 사이트에는 미배포.

## 구현
- scrap-web: 가입·기업 정보 수정에서 주소 검색 결과를 선택하면 지도 핀 표시. 클릭/드래그 수정 유지. 주소 변경 시 좌표/검색 결과 초기화, 늦은 검색 응답은 무시.
- scrap-server: 인증된 POST /api/v1/companies/location-search. Photon을 통한 국내 위치 후보 최대5개, 다른 도로·건물번호 제거, 좌표 유효성 확인. 초당1회, 512개/24시간 메모리 캐시. 기존 기업 좌표 저장 API 사용, DB migration 없음.
- scrap-infra: 검색 활성화·제공자 URL 환경변수 전달.

## 실제 웹 검사
별도 가상 기업 계정으로 공개 주소를 검색했다. 서울시청은 테스트용 위치이며 해당 기관의 가입/실사업장 검증이 아니다.
1. 서울특별시 중구 세종대로 110 → 서울특별시청 등 주소 결과 표시.
2. 서울특별시청 선택 → 지도 핀 및 37.56679, 126.97842 표시.
3. 기아자동차로 95로 주소 변경 → 이전 핀 제거, 결과 없음 안내. 부정확한 좌표를 대신 저장하지 않음.
4. 서울 주소로 다시 선택 → 기업 등록 완료 → 기업 정보에서 거리 비교용 좌표 등록 확인.
5. 기업 정보 수정에서 같은 주소의 서울도서관 결과 선택 → 저장 → 새로고침 → 37.56635, 126.97788 및 지도 핀 복원 확인.

서버 pytest 612 passed, 웹86 passed, Ruff 통과. Docker 웹·서버 빌드 성공.

## 한계
키 없는 Photon은 공개 OSM 데이터의 상세 주소 누락이 있다. 실제 기아 화성 상세주소는 미검색이었다. 도로/지역 대표점은 건물 위치와 구분해 표시하고 사용자가 핀을 조정한다. 소규모 단일 워커에서 사용하며 공개 서비스는 가용성을 보장하지 않는다. 다중 서버·운영 확장 시 자체 Photon/국내 주소 제공자와 공유 제한을 준비해야 한다.
