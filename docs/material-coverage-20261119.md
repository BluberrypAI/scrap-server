## 4. UI 통합과 문진 경계

- 팀원 web PR #67의 카드 표, 공개 자료/AI 상세 접기, 공정 바로가기를 로컬 통합했다. 전 공정을 합친 도로거리 정렬과 기존 `process_match`, 사진 검토, 수신 계정 안내는 보존했다.
- 확정 후 현재 형태를 선택·수정하는 화면을 제거했다. 알려진 형태는 그대로 물량 등록에 전달하고, 누락된 경우 문진 형태 연결 대기를 표시한다.
- diagnosis 엔진 질문·분류 규칙은 수정하지 않았다. 확인 시점 develop에는 구조화된 세부 형태 출력이 아직 없다. 기존 수신 어댑터의 제한적 사용자 원문 읽기는 유지되며, 향후 `handoff.facts.input_form`이 오면 이를 우선한다.
- 실제 웹에서 형태 누락 안내와 기존 인수 요청·예정 카카오 경로를 확인했다. 사용자 진행 중인 인계 건은 수락하거나 변경하지 않았다. 별도 기존 합성 PP 시험 물량에서 통합 카드 렌더를 확인했다.

## 5. 남은 공백

1. 문진 담당자의 소재·현재 형태 및 분류 경우의 수 갱신 후 구조화 인계·코드 일치 E2E 재검사.
2. PE 일반 베일, 수도권 PE 폐비닐 베일, PET 플레이크, 알루미늄 음료캔 수행 사업장 공개 자료 보강.
3. 실제 업체의 수신 계정·현재 반입 조건과 이번 물량 수락 확인. 명부 적재 또는 AI 공정 관련 판정으로 대신하지 않음.
