# 과도한 사업장 공정 입증 제거

2026-11-20 T-185. 회사 자료에 해당 소재 취급이 있으면 문의 후보로 찾고, 구체 공정·반입조건은 수신 업체가 협의 후 수락한다.

공정경로는 현재 소재/형태에서 가능한 다음 가공과 예상 산출물을 연결한 기준표다. 예를 들어 PE 파쇄품→펠릿, PE 펠릿→컴파운드는 서로 다른 다음 가공 후보다. 전체 실제 공급망을 미리 확정하는 의미가 아니다. 회사의 소재 취급으로 후보를 찾더라도 그 사업장의 세척기·압출기가 입증됐다고 승격하지 않는다.

## 변경

- route가 회사 전체 자료·소재/제품 목록을 후보 근거로 사용할 수 있게 한다. 기존처럼 정확한 사업장별 공정 수행 문구까지 요구하지 않는다.
- 서버는 사업장 역할 추정이라는 이유로 가까운 업체를 거리 순위에서 제외/후순위로 보내지 않는다. 실제 도로거리순 최대5개 선별은 유지하고 공개 자료의 소재 관련성은 AI에 전달한다.
- 웹의 검토 이름은 '취급 소재가 맞는 업체', 다음 확인은 '세부 공정·반입조건은 업체와 대화'다. B 수락·QR·실제 산출물은 유지한다.
- 실제 다른 소재·명시 취급 금지·출처/인용 문제·모델 미완료·사진 모순을 통과시키지 않는다. 새 증빙 질문은 추가하지 않는다. 기존 API/DB/문진 엔진/완료 허용 상태 변경 없음.
