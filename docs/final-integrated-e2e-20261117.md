## 실제 웹에서 한 일

| 단계 | A→B에서 종료 | A→B→C |
| --- | --- | --- |
| 문진 | PP 파쇄품 관련 자유 입력 → 51-03-01 → 확정 | PP 사출 잔재 자유 입력 → 51-03-01 → 확정 |
| 최초 물량 | 파쇄품 1,000kg, 설명·사진 업로드 | 제조 잔재 1,000kg, 설명·사진 업로드 |
| 업체 검토 | 9개 조합 요청, 선택한 독산 화성의 검토 완료 확인 | A 단계 14/14, B 산출물 단계 9/9 검토 완료 |
| 기업 수락 | 수신 기업이 별도 로그인해 수락 | B 조건부 수락 → A 추가자료 → B 최종 수락 → 이후 C 별도 수락 |
| QR | A가 발급한 링크를 수신 계정으로 열어 입고 | A→B QR, B→C QR을 각각 수신 계정으로 열어 입고 |
| 실제 산출물 입력 | 수신기업이 펠렛 920kg 기록 | B가 파쇄품 950kg 기록 → 새 사진·B 위치로 C 검토 → C가 펠렛 900kg 기록 |
| 종료 | 완료 근거·용도·확인 입력 후 완료 | C가 완료 근거·용도·확인 입력 후 완료 |
| 원래 배출기업 | A 재로그인 후 920kg 완료 확인 | A 재로그인 후 2회 인계와 900kg 완료 확인 |

직접 경로의 전체 9개 결과는 산출물 저장 전에 별도 보존하지 않았다. 이 실행에서 9/9 전체 완료를 입증했다고 확대하지 않는다. 두 단계 경로의 14개·9개 결과는 각각 저장해 전부 완료된 것을 확인했다. **검토 완료에는 '근거 추가 확인 필요'도 포함되며 반입 승인과 다르다.**

시험 계정:
- A: `e2e-20261117-a@example.com` — 가상 화성 제조기업
- 중간 B: `pp-sort@example.com` — 새롬이엔지 화성 제2공장에 연결한 가상 계정
- 최종 수신: `pp-pellet@example.com` — 독산 화성에 연결한 가상 계정. 직접 경로에서는 이 계정이 B 역할이다.

QR은 브라우저 링크로 시험했으며 휴대전화 카메라로 인쇄물을 스캔한 시험은 아니다. 사진은 [공개 PP 세척 연구 보고서 Figure 6.1](https://edepot.wur.nl/518299)의 시험용 예시이며 해당 물량을 실제로 촬영한 사진이 아니다.

## 발견해서 고친 것

- **14개 중 2개 AI 시간초과:** 같은 물량을 다시 검토하면 성공한 12개도 다시 호출되던 문제를 고쳤다. 같은 사진·설명·문진/R유형·사업장·참조자료 버전에서는 완료한 결과를 유지하고 미완료 후보만 개별 호출한다. 최대 3개 동시, 전체 175초 제한이다. 실제 재시도로 14/14를 회복했고 기존 12개 결과가 바뀌지 않았음을 대조했다.
- **검토 완료 수 표시:** 공정·업체 조합별 완료/미완료 수를 표시하고, 미완료 후보만 재시도한다는 안내를 추가했다.
- **도로거리 선택 연동:** 카카오모빌리티 길찾기 키가 있으면 현재 보유 기업 위치→전체 후보 위치를 조회한다. 도로거리가 확인된 후보끼리 최대 5곳을 지도에 표시한다. 목록과 AI 검토 대상은 줄이지 않는다. 모르는 도로거리를 직선거리와 섞어 순위를 매기지 않는다.

사진·산출물·추가답변·사업장·근거가 바뀌면 이전 검토를 그대로 재사용하지 않는다. B가 산출물을 기록하기 전에는 C 후보 검토·완료 버튼이 없었고, 입고 1,000kg보다 큰 산출물 1,001kg도 웹에서 차단됐다.

## 아직 별도로 필요한 것

1. **도로거리 실호출:** 유효한 길찾기 키가 없다. 기존 지도 토큰은 거리 API에서 401이었다. 카카오 코드·오류 처리는 준비됐지만 현재 화면은 '직선거리·도로거리 미확인'이다. `KAKAO_MOBILITY_REST_API_KEY` 설정 후 실제 값 확인이 필요하다. 기본 자동차 경로이며 화물차 통행 제한·운송 견적·실제 GPS 이동 기록은 아니다.
2. **Google/Microsoft 소셜 로그인:** 로컬 client ID/secret 미설정으로 진입 503. 개발용 계정 검사를 소셜 로그인 검증으로 대신하지 않는다.
3. **실제 업체 계정·반입 승인·계량 증빙:** 이번 시험의 수신 연결과 수락은 synthetic이다.
4. **모든 소재 완료:** 이번 전체 클릭 시험은 PP 두 경로다. PE·PS 베일 일부 근거 부족과 페놀수지·PU폼·고무 미지원은 그대로이며, 다른 소재까지 이번에 전부 완료 시험한 것은 아니다.

이 문서가 최신 통합 재시험 결과다. 이전 실행은 [첫 통합 보고서](full-login-e2e-20261117.md)에 별도로 남아 있다.
