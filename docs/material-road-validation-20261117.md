# B→C 도로거리와 재질별 후보 검사

2026-11-17 로컬 통합 환경 기준입니다. **B→C 출발지는 B의 등록 사업장입니다. 다만 지금 데이터로 모든 경우에 5곳을 표시할 수는 없습니다.**

## 무엇을 확인했나

- 실제 PostgreSQL 공정 자료로 PP·PE·PET·철·알루미늄의 지원 코드/형태 33조합과 첫 처리 후 산출물 61조합, 총 94조합을 검사했습니다. B 후속 조회에는 실제 산출물 상태를 전달했습니다.
- 화성의 서로 다른 가상 A/B 좌표로 FOSSGIS OSRM 자동차 도로 API를 실제 호출했습니다. 좌표가 있는 후보는 모두 응답을 받았습니다. 코드별로 출발지·후보를 대입하는 모듈 검사이며, 94개 모두 문진·QR을 브라우저에서 수행했다는 뜻은 아닙니다.
- 그 94개 응답을 실제 웹의 지도 후보 선택 함수에 넣었습니다. 거리 확인 후보 중 최대 5곳, 거리순, 업체 중복 제거, 나머지 목록 보존 검사가 통과했습니다.
- 별도로 5재질 각각 A→B 수락·QR 입고·B 산출물·B→C 수락·QR 입고·C 완료까지 인증된 API 회귀 테스트를 추가했습니다. 이 자동 테스트의 문진·AI·도로 서비스는 모의 응답입니다. 전체 서버 테스트 **514개 통과**, Ruff 검사·포맷 검사 통과.
- 실호출 검증은 로컬 DB에 **B가 처리한 직후 상태의 가상 물량 5개**를 만들어 B 계정으로 정식 후보 조회 API를 호출했습니다. 이 물량은 실제 인계 이력으로 주장하지 않도록 화면에 가상 상태임을 표시합니다. Azure 검토와 OSRM은 실제 호출이며 사진은 없는 합성 상태 설명을 사용했습니다.
- 5재질의 B 후보 **23개 모두 Azure 응답**을 받았습니다. 공개 근거 확인 6개, 추가 근거 필요 17개, 호출 실패 0개입니다. PP 9개·PE 7개·PET 2개·철 3개·알루미늄 2개이며 도로거리 순위는 위 검토 판정과 별도입니다.
- 실제 웹에서도 B로 로그인해 다섯 물량을 열었습니다. PP 지도 3곳, PE 3곳, PET 1곳, 철은 목록 3곳/지도 없음, 알루미늄 2곳을 확인했습니다. 별도로 A의 새 PE 문진을 웹에서 확정해 폐필름 후보 17곳·도로 확인 9곳·지도 5곳 연결까지 확인했습니다.

## A→B: 대표 형태별 실제 조회 결과

`도로거리 확인`이 5보다 작으면 지도에도 그 수만 표시됩니다. 후보 수는 수락 업체 수가 아닙니다.

## B→C: B의 산출물에 따른 결과

가상 B 사업장 좌표는 37.15, 126.88입니다. A는 다른 화성 좌표입니다. 인증된 후보 응답의 `origin_company_id`, `origin`, `origin_label`이 B로 기록됐습니다.

| B가 기록한 상태 | C 후보 업체 | 도로거리 확인/지도 | 확인된 순서 |
|---|---:|---:|---|
| PP 파쇄품 | 9 | 3 | 독산 화성 17.7km → BGF 예산 64.2km → HCR 파주 81.9km |
| PE 파쇄품 | 7 | 3 | BGF 예산 64.2km → HCR 파주 81.9km → 구일 합천 298.1km |
| PET 플레이크 | 2 | 1 | BGF 예산 64.2km |
| 절단·정리된 철스크랩 | 3 | 0 | 세 업체 모두 좌표 없음 |
| 알루미늄 스크랩 | 2 | 2 | 제이엠테크 김포 83.9km → 울산알루미늄 350.3km |

같은 독산 화성도 A 출발은 12.9km, B 출발은 17.7km입니다. A의 거리를 그대로 재사용하지 않았습니다. B가 펠릿·빌릿·알루미늄 판재 등 종료 가능한 산출물을 기록한 경우는 C 선택을 강제하지 않습니다. PET 플레이크처럼 완료 가능하면서 선택적 후속 공정도 있는 상태가 있습니다.

## 아직 부족한 것

1. **좌표 없는 후보 사업장 30곳.** 공정에 연결돼 목록에는 나오지만 지도에 표시할 수 없습니다. 특히 현대제철 인천·대한제강 녹산·한국철강 창원의 좌표가 없어 철 B→C 도로 순위가 비어 있습니다. PET 선별 업체와 PP·PE 펠릿 업체도 누락돼 있습니다. 확인된 사업장 주소와 좌표 출처를 보강해야 하며 시·군 중심점으로 대신 채우면 안 됩니다.
2. **PE 일반 베일의 반입 근거 없음.** 처음부터 베일인 입력 2개 코드와 PE 선별→베일 후속에서 후보가 없습니다. PE 폐비닐 베일은 별도 공정 후보 1곳이 있지만 좌표가 없고, 산출물 `pe-film-recovered-product`의 구체 상태·사용처가 확정되지 않아 자동 종료하지 않습니다.
3. **AI 검토 완료와 반입 가능은 다릅니다.** 후보별 근거 추가 확인과 수신 기업의 허가·수용·로트 수락은 계속 필요합니다. 공개 근거가 부족한 후보를 거리가 가깝다는 이유로 통과시키지 않습니다.
4. **화물차 전용 길찾기는 아님.** OSRM 최단시간 자동차 경로의 거리로 비교하며, 화물차 높이·중량 제한이나 최단거리 보장은 없습니다. 공개 서버는 소규모 단일 워커 로컬 시연용입니다.

이번 작업은 거리·후속 후보 연결 검사입니다. 신규 5재질 전부에 대해 실제 브라우저 문진부터 QR 완료까지 재시연했다는 의미가 아닙니다. 기존 PP 전체 웹 완료 기록은 [이전 통합 결과](final-integrated-e2e-20261117.md)를 참고하세요.
