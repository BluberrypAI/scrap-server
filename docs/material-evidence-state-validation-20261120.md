# PE 베일·PET 플레이크·수도권 캔 및 상태별 검토 확인

2026-11-20 로컬 통합 환경에서 확인했다. 실제 업체의 공개 공정·주소를 사용했고 물량·오염 설명은 시험 입력이다. 외부 업체에 연락하거나 운영 DB를 변경하지 않았다.

## 추가한 연결

| 입력 | 연결 | 공개 근거와 한계 |
| --- | --- | --- |
| PE 일반 압축 베일 | 대영 논산 → PE 압축품 재생수지 가공 검토 | 2021 팩토리온 원자재·생산품, 2025 등록공장의 동일 지역·생산품, 2026 논산시 처리업체 주소를 대조. 개별 해체·분쇄·세척 설비와 현재 베일 규격은 미확인 |
| PET 플레이크 | 삼양에코테크 시화 → 재생 PET 칩 가공 | 2024 보고서의 시화공장 칩 설비·생산품과 주소. 외부 플레이크 수탁·이번 물량 수락은 별도 확인 |
| 알루미늄 음료캔 | 신성리사이클링 고양 → 선별·압축 | 공단의 캔 선별·압축 기록과 경기도 공개 기업정보를 동일 주소로 대조. 순환자원 인정기간은 2026-02-02에 만료되어 현행 인증으로 표시하지 않음 |

시설 **62→64곳**, 공정·시설 연결 **129→132개**다. 시화는 기존 사업장에 공정을 추가했고, 논산·고양은 새 사업장이다. 신규 주소는 카카오 Local exact 주소 검색 좌표를 저장했다. 별도 전국 명부 **9,604행은 변경하지 않았다**.

PE 일반 베일은 0→1곳, PET 플레이크는 2→3곳(수도권 0→1), 알루미늄 캔은 3→4곳(수도권 1→2)이다. 이는 공개 공정 관련성 기준이며 현재 인수 승인 건수가 아니다. PE 폐비닐 전용 베일은 일반 베일과 구분한다. PS 일반 베일은 여전히 공백이다.

## 실제 AI·도로거리

Azure Astra와 카카오 자동차 `priority=DISTANCE`를 실호출했다. 화성 A의 저장된 사업장 위치 기준으로 새 연결은 다음과 같다.

| 후보 | 카카오 도로거리 | 결과 |
| --- | --- | --- |
| 대영 논산 | 119.344km | 공정 관련성 matched, 물량 설명 검토 완료 |
| 삼양에코테크 시화 | 26.730km | 공정 관련성 matched, 물량 설명 검토 완료 |
| 신성리사이클링 고양 | 70.682km | 공정 관련성 matched, 물량 설명 검토 완료 |

도로거리 확인 및 AI 검토를 마친 서로 다른 사업장을 최대 5곳 선별한다. 부족한 후보를 5곳으로 늘려 만들지 않는다. 신규 PE 연결은 산출물을 펠릿으로 추정하지 않고 `pe-recycled-resin`으로 두었으며, 이 상태만으로 자동 완료하거나 펠릿 후속 경로로 넘기지 않는다.

처음 PE AI 시험에서 모델이 등록공장의 생산품을 공정 관련성 근거로 선택했지만, 요약이 업체명·제품명·주소의 나열이라 인용 검사가 보류했다. 원본의 **생산품 필드**임을 명확하게 요약하고 새 캐시 키로 재검토해 통과했다. 인용 검증이나 보류 정책을 우회하지 않았다.

## 상태·캐시

- PET 병은 병 선별·압축/세척·분쇄 공정이 나온다. PET 플레이크는 후속 재생 칩/압출 공정이 나온다. 같은 사업장이라도 선택한 공정은 다르다.
- 새롬이엔지 화성 제1공장의 `pet-bottle-wash-grind` 후 실제 산출물을 플레이크 90kg으로 가정한 후속 요청에서도 플레이크 공정만 반환했다. C 후보까지의 카카오 도로거리는 B 위치에서 각각 시화 34.411km, BGF 54.297km, 순창 231.845km였다. 최초 분류번호를 후속 물량의 확정 번호로 재사용하지 않는다.
- 같은 플레이크에서 설명만 미세척·진흙·수분 있음으로 바꾸면 목록을 임의 재분류하지 않고 세척·건조 확인사항이 달라진다. 새 상단 공정 탭에 해당 확인사항을 표시하고, 실제 후보가 없는 공정의 빈 탭은 숨긴다. 단계·상태 변경 시 이전 선택과 검색 상태를 초기화한다.
- 공개 자료 판단은 PostgreSQL에서 7일간 재사용한다. 사진 관찰과 현재 물량 판단은 별도 캐시다. 상태·중량·설명·사진 또는 관련 근거·모델 버전 변경은 해당 판단을 다시 검토한다.
- 동일 PET 플레이크를 반복한 실호출은 **21.47초→1.19초**, 두 번째 모델 호출 **0회**였다. 설명을 오염 상태로 바꾸면 공개 3건은 재사용하고 물량 3건은 새로 검토했다. 이는 해당 시험의 측정값이며 모든 환경의 응답시간을 보장하지 않는다.

## 웹·회귀 확인

- `localhost:5178`에서 새 PET 문진을 만들고 51-03-01 확정→대화에서 플레이크 형태 전달→100kg 물량 저장→실제 AI 검토→2개 공정·3개 업체·카카오 지도/도로거리 표시를 확인했다. 형태를 다시 고르는 화면은 없었다.
- 상태별 실모델 응답을 같은 `CandidateBrowser` 인스턴스에 적용한 별도 로컬 비교 화면에서 병→플레이크, 미세척 표시, B 후속 상태, 후보 없음→다른 소재 전환을 확인했다. 이 비교는 실제 모델 응답의 UI 재생이며 기업 간 QR 실물 시험이 아니다.
- 기존 사용자 인수 요청은 변경하지 않았다. 새 연결 업체의 실제 회원 가입·현재 수락, PE 미확인 산출물의 완료, 실제 운송·입고는 이번 시험에서 확인하지 않았다.

서버 `pytest` 684개, Ruff 검사, 웹 테스트 105개 및 Docker 웹 빌드가 통과했다. 구체적 호출 수는 [검증 요약 JSON](verification/material-evidence-state-20261120.json)과 PR CI를 참고한다. 실제 웹에서 같은 처리 건의 재검토도 공개 캐시 3건·물량 캐시 3건을 재사용하여 모델 호출 0회를 확인했다. 기존 API 필드는 삭제·이름 변경·타입 변경하지 않았다. 문진 엔진은 수정하지 않았다.
