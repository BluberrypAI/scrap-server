2026-11-16 확인. **업체가 하는 공정과 이번 물량을 받아준다는 것은 다릅니다.**
아래 수치는 공개 공정을 연결한 조사 후보이며, 허가·수락·단가·여유 용량은 확정하지 않습니다.

## A → B 다음에 어떻게 이어지나

- 철스크랩: A → 광주 절단 업체 B → **B가 실제 가공 철스크랩을 기록** → 인천·녹산·창원 제강 후보 C. 절단 직후에는 완료가 아닙니다.
- 알루미늄캔: A → 화성 선별 업체 B → **B가 실제 알루미늄 스크랩을 기록** → 김포 그래뉼/기존 판재용 원료 공정 후보 C. B의 산출물을 A가 미리 확정하지 않습니다.
- 이미 알루미늄 스크랩이면 김포 공정을 첫 B 후보로 조회할 수 있습니다.
- 업체 수락·QR 입고·처리 결과 기록은 기존 계약을 따릅니다. 새 업체를 실제 가입 기업이나 수락한 기업으로 자동 등록하지 않았습니다.

## 아직 연결하지 않은 경우

- 일반 **PE·PS 압축 베일 수령**: 출하 베일을 만드는 업체는 늘었지만, 베일을 받아 다음 공정을 수행한다는 국내 사업장 근거는 부족합니다. 베일 해체와 반입 규격 자료가 더 필요합니다.
- PU폼·고무·페놀수지: 현재 문진 번호와 사유는 표시하지만 검수된 후속 공정·업체가 부족해 보류합니다.
- 일반 비철: 알루미늄으로 특정한 뒤에만 알루미늄 공정을 조회합니다. 구리·납·아연을 모두 같은 공정으로 보내지 않습니다.
- 양정수지의 최근 원문, SP네이처 남안성의 사업장별 설비, 효성자원의 PET 투입 형태 등은 추가 확인 대상으로 남겼습니다. 그룹 전체 설비·판매 제품명만으로 승격하지 않았습니다.
- 서울·경기 모든 소재·형태에 5곳씩 있다는 뜻은 아닙니다. 가까운 후보가 적거나 좌표가 없으면 실제 개수 그대로 표시합니다.

## 검증과 재현

[번호·형태·출발지별 전후 수치](capital-region-coverage-20261116.json)는 서울·화성·파주·안성·남양주 **합성 출발점**에서 검사한 결과입니다. 위치가 바뀌어도 AI 검토 후보가 잘리지 않으며, 지도에는 좌표가 있는 가까운 업체만 최대 5곳 표시됩니다.

```powershell
# 최신 server 이미지를 만든 뒤 PostgreSQL 참조 데이터 갱신
docker compose up -d --build server
docker compose run --rm server-seed

# scrap-server에서 번호·형태·출발지 검사
uv run --project backend python scripts/capital_region_coverage.py --output coverage.json
uv run --project backend python scripts/audit_live_catalog.py --base http://localhost:5178 --output catalogue.json
uv run --project backend python scripts/audit_diagnosis_routes.py --output diagnosis.json
uv run --with playwright --project backend python scripts/audit_route_browser.py --input diagnosis.json --output browser.json
```

실제 DB 카탈로그 조회 **212회**에서 현재 지원 소재의 **63공정·123연결**에 도달했습니다. 참조의 나머지 5공정·5연결은 MVP 문진 대상이 아닌 종이 자료이며, 지원되는 것처럼 합산하지 않습니다. 산출물 순회에는 합성 상태를 입력했으므로 실배송·현장 검증과 구분합니다.

최종 결과는 [검사별 기록](capital-region-validation-20261116.json)에 저장했습니다.

- 서버 SQLite **477개 통과**. PostgreSQL도 477개 통과했으며, 위치 자료 보강 후 재실행에서는 연결 설정 중 Windows 시간초과 2개가 발생했습니다. 나머지 475개와 같은 2개 재실행이 통과했습니다.
- route **550개 통과·72개 환경 의존 검사 생략·24개 하위 검사 통과**. 변경 파일 Ruff 및 포맷 검사 통과.
- 실제 버튼 문진 **18선택지·12번호**, 15선택지에서 후보 조회 가능. 형태 조합 56개 중 53개 후보, PE·PS 일반 베일 3조합 보류. PU·고무·페놀은 별도 미지원 표시.
- 실제 Edge **59개 검사 통과**: 세부 재질·형태 선택, 후보·보류 화면, R유형·법령 출처 확인.
- 실제 Azure: 첫 공정 7조합 + B의 산출물 후속 2조합, **67회 후보 검토·65개 고유 연결**. 최종 공개 근거 확인 21회·근거 부족 46회·호출 불가 0회. 원래 R유형도 첫 공정 검토에 전달했습니다.
- **신규 19연결은 모두 AI 검토했고 7개는 근거 확인, 12개는 추가 자료 필요**입니다. 특히 일부 선별장의 구체 투입 형태와 안성 PE 분쇄품의 반입 형태·공정 상세가 부족합니다. 승인으로 바꾸지 않았습니다.
- “알루미늄캔”이 원문에 있어도 “음료캔·폐캔” 표현만 인식해 보류하던 route 검증 오류를 수정했습니다. 동일 화성 업체를 Azure로 다시 검토해 근거 확인 응답을 받았고, 철제 캔·다른 형태·반입 금지는 통과하지 않는 회귀 검사를 추가했습니다.

로컬 서비스 재빌드 중 일부 요청이 끊겨 문진 결과와 모든 형태를 재조회했고, 미완료 문진 두 건은 새로 실행했습니다. route 재빌드 중 호출 불가였던 캔 3후보도 서비스 준비 확인 후 재검토했습니다. 최종 수치는 이 재검증 결과이며, 원래 장애 기록도 검사 파일에 남겼습니다.

공개 근거 확인은 **지금 이 물량을 받겠다는 승인이나 모델 정확도**가 아닙니다. 새 사업장 전체의 수신 기업 가입·실배송·QR 완료를 시험했다는 뜻도 아닙니다.
