## 위치를 확인한 방법

업체 공식 사업장 안내·기존 공공 공장 명부의 주소와 건물 단위 주소 지도를 대조했다. 이전 사업장·동명 업체·본사 주소·시군 중심점은 사용하지 않았다. 새롬 제1공장과 제2공장, 독산 25번과 DSPL 27번은 별도 위치다. 용성케미칼은 지번 가일리 482를 도로명 가일길 46-11로 정리했다.

좌표는 **건물 대표점**이다. 화물차 출입구 실측 좌표나 현장 인수 가능 인증은 아니다. UTMK 값은 EPSG:5179→4326으로 변환했고, 지도 화면의 중심점 대신 주소 마커를 사용했다. 도로 스냅 500m 제한은 유지한다.

좌표마다 위치 근거 ID, 확인일, 원문 해시를 저장했다. 기존 `location_source_url` 응답으로 근거 링크를 전달한다. 원문·지도 이미지·개인 담당자 정보는 레포에 넣지 않았다. 위치용 출처는 AI 전송 허용 자료로 추가하지 않았다.

## 검증 결과

- 실제 PostgreSQL 참조 자료를 다시 적재했다. 공정 69개·검수 시설 62개를 유지하고, 기존 회원·인계·업체 명부는 삭제하지 않았다.
- PP·PE·PET·철·알루미늄 A 입력 33조합과 B 산출물 61조합, **총 94조합**을 실제 OSRM으로 재조회했다. 반환 후보의 좌표 누락 0건, 도로 조회 실패 0건이다. 후보 자체가 없는 형태까지 새 처리능력이 생겼다는 뜻은 아니다.
- 같은 94응답을 웹의 실제 지도 후보 선택 함수에 대입해 거리순·최대 5곳·업체 중복 제거·목록 보존을 확인했다.
- 서버 회귀 테스트 **518개 통과**, Ruff 검사·포맷 검사 통과. 기존 좌표 없음 가정 4개는 위치 출처의 독립성과 시설별 범위를 검증하도록 바꿨다.
- 실제 웹에서 B 계정으로 철 물량의 업체 검토를 다시 실행했다. Azure 검토 3/3 완료, 지도 핀 3곳과 B 출발 사업장을 확인했다. 현대제철 인천 54.0km, 한국철강 창원 344.6km, 대한제강 녹산 371.0km로 표시됐다.
- B 계정의 인증된 정식 API로 PP·PE·PET·철·알루미늄 가상 물량 5건을 조회했다. 모두 현재 담당 B의 사업장 좌표와 실제 산출물 상태를 사용했다. 도로거리 23/23 확인, Azure 검토 결과 23/23 수신(공개 근거 확인 6, 추가 근거 필요 17, 호출 실패 0). 철은 직전 브라우저에서 완료한 검토를 재사용했다. 나머지는 변경된 참조자료로 재검토했다. 위치 확보와 AI의 반입 근거 판단은 별개다.

### 검증 범위와 남은 일

- 이번 실행은 좌표·B 후속 후보·도로거리·지도 표시 검증이다. 94조합의 문진부터 QR 완료까지 새로 브라우저에서 수행한 것은 아니다. 기존 PP 전체 웹 검증은 [별도 기록](final-integrated-e2e-20261117.md)을 참고한다.
- 일반 PE 압축 베일은 직접 반입 근거 부족으로 후보 0곳인 경우가 남아 있다. 필름 베일과 일반 베일을 같은 것으로 처리하지 않았다.
- 철 후보 3곳의 위치는 확인됐지만 수신 기업 계정이 연결되지 않아 인수 요청은 비활성이다. 실제 업체 가입·연결·수락이 필요하다.
- 좌표는 건물 대표점이다. 운송 차량의 출입구·통행 제한·현재 가동/인수 여부는 별도 확인 대상이다.
- OSRM 공개 서버는 현재 단일 워커 로컬 시연용이다. 운영 배포에는 자체 호스팅 또는 계약된 도로 서비스가 필요하다.
