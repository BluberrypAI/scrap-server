# 11월 18일 서버 최종 통합 검증

최신 develop, 팀원 PR #58(세부 번호 미확정 지정폐기물의 제출 전 서류 초안)과 기존 로컬 인계 보완을 함께 적용했다.

## 바뀐 동작

- 사진·설명 불일치 확인/수정과 비폐기물 사진 차단을 구분한다. 캐릭터·문서 사진은 확인 체크나 설명 변경으로 우회하지 못하며 실제 사진 교체 후 재검토가 필요하다. 최초 분류번호는 자동 변경하지 않는다.
- 로그인한 사용자는 기업 가입 전에도 주소를 검색할 수 있고, 인계 도로 경로는 해당 참여 기업만 조회한다. 카카오 REST 키는 서버에만 둔다. 검색·길찾기 원문은 업무 DB에 저장하지 않는다.
- 인수 수락과 실제 운송 시작을 분리했다. 기존 accepted 상태와 QR API는 유지하고 dispatch 기록·권한 필드를 추가한다.
- B→C 도로 구간은 B에서 출발하며 좌표 누락·외부 실패를 직선 경로로 위장하지 않는다.
- 에이전트 문서 동기화 검사는 Windows의 Markdown LF/CRLF만 같은 내용으로 본다. 실제 내용 변경과 바이너리 차이는 계속 실패한다. 원본 에이전트 지침은 수정하지 않았다.
- DB 모델·마이그레이션 변경은 없다. 기존 JSON 업무 기록에 출발 위치·dispatch 정보를 추가한다.
