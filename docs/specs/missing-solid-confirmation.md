# 문진에 빠진 고체 상태 확인 (2026-11-15)

사용자 요청: 소재별 실제 문진부터 처리경로·인계까지 연결 확인.

금속캔 문진은 분류 확정 시 physical_state를 요구하지 않는다. 기존 경로 연결은 고체 정보가 없으면 보류하여 선택 자체가 불가능했다.

- 경로 조회/검토 및 물량 등록에 선택 boolean `solid_confirmed`를 추가한다. 기본 false이며 엄격한 boolean만 받는다.
- 문진의 상태가 비어 있을 때만 사용자의 고체 확인을 이용한다. 문진에 액체·슬러지 등이 있으면 이 확인으로 덮어쓰지 않는다.
- `requires_solid_confirmation` 응답과 확인 체크박스로 추가 확인한다. 미확인 상태에서는 업체 조회·물량 등록을 진행하지 않는다.
- 사용자의 확인 사실은 처리 건 경고/기록에 남기되, 확정된 문진 원본·분류번호·검토 등급은 변경하지 않는다.
- 알루미늄 캔 선택은 기존과 같이 사용자가 직접 해야 하며 금속캔 번호를 모든 알루미늄 스크랩에 일반화하지 않는다.
