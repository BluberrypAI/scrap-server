# Spec: 반입 형태 근거와 수도권 후보 후속 보강

상태: 확정 — 사용자 직접 요청. 관련 작업: T-158.

## 목적과 범위

T-157에서 AI가 추가 근거를 요청한 12개 연결을 원문과 다시 대조한다.
PE·PS 베일을 실제 받는 국내 사업장을 조사하고, 수도권의 확인 가능한
투입 형태·공정·산출물 근거를 추가한다. 기존 API와 업체 최종 수락 절차는 유지한다.

## 구현 기준

- 원문 URL·해시·위치·확인일을 기록한다. 원문 전체는 외부 모델에 보내지 않는다.
- 베일 판매와 베일 투입, 거래 중개와 현장 처리를 구분한다.
- LDPE 필름 자료를 모든 PE 경질·베일로 확대하지 않는다.
- 다른 사업장이나 불명확한 주소의 좌표를 가져오지 않는다.
- 부족한 근거는 그대로 표시한다. AI 통과를 만들기 위해 판단 기준을 낮추지 않는다.
- 문진 번호·R유형·현재 형태가 실제 웹 및 AI 검토까지 보존되는지 재검사한다.

## 완료 조건

- [x] 12개 연결과 베일 검색 단서별로 확보/부족 사실을 기록한다.
- [x] 확인된 사업장과 투입 형태만 카탈로그에 연결한다.
- [x] 다른 형태로 잘못 확대되지 않는 테스트를 통과한다.
- [x] 문진·브라우저·전체 공정 HTTP·실제 Azure 검토를 재실행한다.
- [x] 결과와 남은 범위를 문서화하고 기존 PR을 업데이트한다.

공개 자료에서 찾지 못한 반입 규격·현재 허가·수탁 가능 여부는 미정으로 남긴다.

결과: 성원산업 화성 LDPE 필름 1연결 추가, 기존 12개 중 한국철강 1개 근거 보강·11개 보류.
