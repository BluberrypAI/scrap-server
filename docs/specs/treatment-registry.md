# SCRAP 처리업체 명부와 단계별 공정 조회

- 관련 기획: SCRAP의 분류 결과 → 다음 공정 → 인계 추적 흐름과 사용자 요청
- 범위: 전국 명부 원본 적재, 폐기물 코드·공정별 업체 조회, PostgreSQL 공정 참조 데이터와 인계 기록
- 경계: 공개 명부 등록은 공정·현행 허가·수용 여력을 보장하지 않음. 참조 공정이 없으면 명부 단서만 제공하고 인계를 생성하지 않음.

## API

- POST /api/treatment/next-step — 현재 로트 상태로 다음 공정과 출처 조회
- POST /api/treatment/facility-candidates — 검수 공정 또는 분류번호로 명부 검색, 지역·직선거리·페이지네이션 지원
- POST /api/treatment/facility-web-search — 로그인 후 PP 다음 공정의 공개 웹 조사 후보를 명시적으로 요청
- POST /api/treatment/intake-review — 현재 사용자 인증과 후보 재검증 후 공개 검토용 요약만 AI 엔진에 전달
- POST /api/treatment/intake-reviews — 현재 공정의 다음 업체 후보 전체를 재산출하고 Astra의 후보별 검토 결과 반환
- POST /api/classification/sessions[/…] — 팀 문진 엔진으로 전달

## 저장

- 공정 참조 데이터와 명부 스냅샷은 scrap-server가 적재하고 PostgreSQL에서 제공함.
- 원본 JSON 전 행을 보존하고, 화면 응답에는 명부 원본 객체와 전화번호를 포함하지 않음.
- 새 적재는 원본 체크섬을 확인하고 트랜잭션으로 교체함. 명부 원본 배포 범위는 미정이며 서버 적재 경로로 관리함.

## PP 근거 검증 시연

- **새롬이엔지 화성 제2공장**은 사업장과 작업 내용의 공개 단서가 있으며, 사출 잔재의 반입 규격과 이번 로트 수락은 미확인입니다. [사업장 공개 공고](https://www.jobploy.kr/ko/recruit/RS0000112388)
- **독산 화성**은 선별 PP 분쇄품·압축품의 공개 원료 사례가 있습니다. 상세 반입 규격, 현행 허가 범위와 이번 로트 인수는 미확인입니다. [베올리아의 사업장 자료](https://www.veolia.kr/ko/plastiloop-hwaseong)
- 공정 공개, 반입 형태 사례, 상세 반입 규격, 현행 허가와 로트 인수를 각각 표시합니다. 공정과 형태 근거는 후보 조사에 사용합니다. 실제 단계별 QR 인계는 보류하며, 로컬에 지정한 시연 계정 간에는 시뮬레이션을 진행할 수 있습니다.
- AI에는 외부 전송 가능으로 표시한 팀 작성 요약만 보냅니다. 모델의 출처 인용과 인계 상태는 따로 표시합니다.

## PP 재활용 유형과 추가 웹 조사

- 문진의 재활용 유형은 사전 분석 여부 그룹별로 전달합니다. 서버는 PP 공정별 관련 유형을 대조해 화면과 조사에 씁니다. 대조 결과는 조사 범위이며 실제 법적 적용 유형과 사업장 허가를 확인해야 합니다.
- 첫 인계에는 배출 로트의 문진 결과를 적용합니다. 다음 인계에는 처리업체가 기록한 실제 산출물의 상태로 조회하며, 원래 로트의 분류번호와 R코드를 후속 산출물에 적용하지 않습니다.
- 웹 조사에는 정해진 공정 키·형태·권역·공개 분류번호·관련 R코드와 전송 가능한 공개 사업장 검색 단서만 전달합니다. 배출기업 이름, 정확한 출발지, 로트 ID, 문서, 수량은 전달하지 않습니다. 새 검색은 화면에서 직접 요청한 경우에만 실행합니다.
- 웹 검색 출처가 있는 단서를 표시하고, 실제 허가·반입 조건은 확인 대기로 유지합니다. 웹 검색 결과에서 인계 버튼을 만들지 않습니다.

## 다음 업체 후보 전체 Astra 검토

- 첫 공정의 B 후보와 처리 결과가 기록된 다음 공정의 C 후보를 자동으로 검토합니다. 공정에 연결된 후보는 지도 표시 여부에 관계없이 모두 검토합니다. 명부 행과 추가 웹 단서는 공정 적합성이 확인되지 않은 조사 목록으로 별도 표시합니다.
- 서버가 공정 후보를 다시 산출하고 전송 허용된 공개 자료 요약, 공정명, 재질·형태, 분류번호·관련 R코드를 AI 서비스에 보냅니다. 원문, 배출기업 위치, 수량, 로트 ID는 전달 대상에서 제외합니다.
- 후속 단계의 AI 검토에는 실제 기록한 산출물 상태를 사용합니다. 최초 폐기물 분류번호·R코드를 재사용하지 않으며, 실제 산출물이나 불일치 증빙 확인이 필요할 때는 검토를 시작하지 않습니다.
- 모델 답변은 후보 ID와 해당 후보의 자료를 대조합니다. 검토 결과 누락과 모델 연결 오류를 표시하며, 일치하는 인용이 없으면 근거 부족으로 처리합니다. 실제 인계 확정은 별도 확인 절차를 거칩니다.

## 예정과 실제 산출물 추적

배출기업과 처리업체가 같은 로트의 처리 예정, 실제 결과와 인계 상태를 공유하는 기업 자원순환·산업 공생 모니터링 흐름입니다.

- 선택한 공정의 예정 산출물과 다음 업체 후보를 배출기업과 처리업체에 미리 보여줍니다. 예정 후보에는 인계 동작을 제공하지 않습니다.
- 수령한 업체는 예정 형태 그대로임을 한 번 눌러 확인하거나 실제 다른 형태를 기록합니다. 미확인을 선택하면 그 사실을 공유하고 처리 중 상태를 유지합니다.
- 형태가 확인되면 다음 후보를 조회합니다. 중량·순도는 미측정으로 남겨 두었다가 다음 인계 전에 확인된 값만 보충할 수 있습니다. 실측 0 kg은 후속 공정 대상이 없습니다.
