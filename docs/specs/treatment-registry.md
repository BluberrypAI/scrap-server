# SCRAP 처리업체 명부와 단계별 공정 조회

- 관련 기획: SCRAP의 분류 결과 → 다음 공정 → 인계 추적 흐름과 사용자 요청
- 범위: 전국 명부 원본 적재, 폐기물 코드·공정별 업체 조회, PostgreSQL 공정 참조 데이터와 인계 기록
- 경계: 공개 명부 등록은 공정·현행 허가·수용 여력을 보장하지 않음. 참조 공정이 없으면 명부 단서만 제공하고 인계를 생성하지 않음.

## API

- POST /api/treatment/next-step — 현재 로트 상태로 다음 공정과 출처 조회
- POST /api/treatment/facility-candidates — 검수 공정 또는 분류번호로 명부 검색, 지역·직선거리·페이지네이션 지원
- POST /api/treatment/intake-review — 현재 사용자 인증과 후보 재검증 후 공개 검토용 요약만 AI 엔진에 전달
- POST /api/classification/sessions[/…] — 팀 문진 엔진으로 전달

## 저장

- 공정 참조 데이터와 명부 스냅샷은 scrap-server가 적재하고 PostgreSQL에서 제공함.
- 원본 JSON 전 행을 보존하고, 화면 응답에는 명부 원본 객체와 전화번호를 포함하지 않음.
- 새 적재는 원본 체크섬을 확인하고 트랜잭션으로 교체함. 명부 원본 배포 범위는 미정이며 서버 적재 경로로 관리함.
