# T-142 플라스틱 공정·사업장 후보 확장

## 문제와 범위

9,604행의 전국 명부와 공정 참조의 15개 사업장은 다른 데이터다. 명부의 코드만으로
PP·PE·PET 처리 능력을 확정하지 않는다. 공식 사업장·제품·공정 자료를 대조한 연결을
추가하고, 현재 형태가 맞는 다음 사업장만 조회·AI 검토·인계 흐름에 연결한다.

## 구현 계약

- DB·공정 참조·명부 대조는 scrap-server가 소유한다. AI 검토는 기존 scrap-route 계약을 유지한다.
- 분류 엔진의 확정 결과를 받으며 여기서 분류번호나 R코드를 만들거나 덮어쓰지 않는다.
- PP/PE의 필름·경질·파쇄품, PET병/베일/플레이크를 연결한다. ABS, PS, PVC, 발포 PS,
  PA6 등은 공개 근거가 확보된 형태와 공정만 추가한다. 미확인 수지·복합재는 보류한다.
- PVC(51-03-03), 발포수지(51-03-06), 폐어망(51-03-08)은 일반수지와 구분한다.
- 원문 URL·확인일·요약·원본 해시와 사업장 주소를 함께 저장한다. 제품 판매나 본사 주소만으로
  처리공장으로 승격하지 않는다. 명부 좌표는 동일 사업장으로 확인된 경우만 연결한다.
- 설비를 보유한다는 사실과 외부 물량을 받는다는 사실을 구분한다. 현재 허가, 가격, 용량,
  로트 인수는 계속 미확인으로 두며 수신 기업의 최종 수락을 요구한다.
- 일괄 공정은 한 사업장 안의 작업으로 표현한다. 내부 세척/분쇄를 별도 운송으로 강제하지 않는다.
- 다음 단계 조회는 미래 사업장 조합을 모두 곱하지 않는다. 현재 단계 후보는 누락 없이 모두
  AI 검토하며 지도용 상위 5개 표시는 별도 유지한다.
- 기존 PP 인계·조건부 수락·QR·실제 산출물 확인을 회귀 검증한다.
- 전국 명부 전수 선별 결과는 조사 대기열로 저장한다. 운반업만 있는 행을 재활용 공장으로
  연결하지 않으며, 코드나 장비명만으로 수지·현재 형태·외부 반입을 추정하지 않는다.
- 기존 역할 추정 21개는 항목별 재검토 기록을 남긴다. 회사 전체 공정과 사업장별 공정을
  구분하며 근거가 없는 연결은 추정 상태를 유지한다.
- PE·PS 베일의 일반 공정 근거와 국내 수행 사업장 근거를 분리한다. 전자는 있어도 후자가
  없으면 업체는 빈 목록, `no_route`, 인계 승인 불가로 남긴다. B가 베일을 만든 경우도 같다.

## 검증 및 배포

### T-143 추가 대조

- 산업단지공단 등록공장 원본의 회사명·주소·생산품을 기존 명부와 대조한다. 이름만 같은 곳,
  다른 소재, 원료 제조와 장비 제조, 제품 산출 형태와 반입 형태를 구분한다.
- 등록 생산품이 재질·공정을 직접 뒷받침하는 경우만 검토 후보에 연결한다. 단순 `재생원료`
  기재만으로 세척·압출 순서를 만들지 않는다. 명부 미일치 업체의 좌표·허가를 추정하지 않는다.
- 과거 역할 추정 검토 기록은 보존하고 이번 재검토 결과를 별도로 남긴다. 공장별 수지·공정
  증거가 새로 생긴 연결만 승격한다. 공개 인증서의 첫 장을 제품·사업장 별첨으로 해석하지 않는다.
- PE/PS 베일은 별도 수령 근거 없이는 계속 보류한다. 농업용 곤포사일리지 필름도 압축
  플라스틱 베일과 구분한다.

소재×형태×번호별 양성/음성 사례, 신규 사업장 근거, B→C 실제 산출물, 후보 전수 AI 전달,
사업장 증식 시 조회 한도, 명부 동명이인/주소 충돌을 테스트한다. 테스트와 조사 후보 수를
보고서로 남긴다. PR로 제공하며 실제 기업 연락·외부 배포·병합은 하지 않는다.

## 구현 결과

47개 사업장·102개 연결(공개 사업장 공정 88, 역할 확인 14), 공정 전환 56개를 적재했다.
원본 명부 9,604행의 플라스틱 관련 4,359행 중 재활용업 2,084행·1,935개 이름/주소 묶음을
공식 공장등록 220,705행과 대조했다. 이름·주소 일치 323묶음은 조사 단서이며 자동 승격하지 않는다.

이번에는 10곳·21개 연결을 추가했다. 직전 미해결 역할 19개 중 BGF 예산 5개는 공장별 공정·
생산품을 대조해 보강했고 CNTK 12개·BGF 화성 2개는 추정을 유지했다. 과거 검토 기록은 보존한다.
PE관·농업용 필름·분쇄품·베일을 구분한다. 확정 handoff의 48개 입력 조합 중 45개에 조사
후보가 있고 PE/PS 베일 3개는 국내 수령 근거가 부족해 보류한다. 문진 메뉴는 확대하지 않는다.

SQLite/PostgreSQL 각각 297개 테스트, 실제 로컬 서버 48개 조회, 공개 요약 12개 후보의
Azure 검토를 확인했다(근거 확인 1, 추가 확인 11, 인수 승인 0). 정확도나 실제 업체 인수
검증은 아니다. [검증 기록](../plastic-facility-expansion.md)·[조사 대기열](../registry-screen/README.md) 참조.
