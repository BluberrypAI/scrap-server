# Spec: PE·PET 전체 공정 목록과 누락 연결 점검

상태: 확정 — 2026-11-20 사용자 지시. 관련 작업: T-182.

## 범위

현재 PostgreSQL 추천 스냅샷의 PE·PET 전체 공정·투입 형태·업체를 추출하고, 전국 명부와 추천 연결표의 차이를 수치로 설명한다. 공공 공장 자료의 원자재·생산품과 사업장 주소를 대조해 확인된 공정 관련 업체를 추가한다. 분류 문진, API 변경, 현장 반입 승인, 외부 업체 연락, 운영 배포는 포함하지 않는다.

## 데이터와 판단

- 2021 팩토리온 원자재 자료는 과거 기록이며 현재 주소는 2025 공장 자료 또는 2026 기업 직접 게시 자료로 대조한다. 동명이인·여러 사업장·수지 재질 충돌은 보류한다.
- 생산품과 원자재에 없는 세척·건조·베일 해체 설비는 추가하지 않는다. 생산품이 펠릿인 업체의 공정 관련성과 특정 형상의 실제 수탁을 구분한다.
- 일반 PE 베일 수령과 PE 재생 펠릿 생산을 혼동하지 않는다. 신규 일반 파쇄품 관련 업체를 베일 후보로 확대하지 않는다.
- 업체별 사실 요약·원본 해시·행 번호·주소·좌표 출처를 남긴다. 원본 전체·전화번호·메일은 추천 자료로 배포하지 않는다.
- 기존 테이블·API·상태 enum은 변경하지 않는다. 공정 스냅샷만 갱신하고 9,604행 원본 명부는 보존한다.
