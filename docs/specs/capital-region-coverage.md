# Spec: 서울·경기 출발 물량의 재질별 업체 후보 확대

| 관련 todo | T-157 |

## 1. 목적

문진 번호가 연결돼도 현재 형태를 처리하는 가까운 사업장이 부족한 문제를 줄인다.
서울·경기 출발지별 후보 수와 사업장 좌표 확보율을 별도로 검사한다.

## 2. 범위

- 포함: 공개된 실제 사업장 공정, 같은 주소 명부 대조, 현재 형태별 다음 후보,
  금속의 중간가공·최종 원료 구분, 문진 코드별 연결 또는 명시적 보류, AI·웹 회귀 검사.
- 제외: 사업장 수를 늘리기 위한 자동 승격, 임의 좌표, 수탁·가격·현행 허가 추정,
  수도권 본사를 지방 공장으로 대체, 모든 번호를 같은 플라스틱 공정으로 연결.

## 3. 요구사항

1. 새 사업장은 원문 URL·확인일·내용 해시·사업장 주소와 투입/산출 방향을 남긴다.
2. 선별 후 베일을 판매하는 곳을 베일 반입 업체로 연결하지 않는다.
3. 절단한 철스크랩은 중간 상태로 남기고, 실제 산출물로 다음 제강 후보를 조회한다.
4. 알루미늄 그래뉼과 판재용 잉곳을 구분한다. 혼합 비철의 전량을 알루미늄으로 간주하지 않는다.
5. 서울·경기·인천 시설 수를 분리한다. 조회 상위 5개와 전체 AI 검토 대상을 구분한다.
6. 미지원 재질·위험성 보류를 성공으로 세지 않는다. 등록 업체 수와 공정 근거 확보 수를 구분한다.

## 4. API

기존 `/api/treatment/next-step`, 문진 건/물량의 공정 조회·검토 API를 유지한다.
카탈로그 공정·상태 추가만 하며 기존 필드를 삭제하거나 변경하지 않는다.

## 5. 데이터

`planning-reference.json`의 출처·사업장·공정·역량을 서버 seed로 PostgreSQL에 적재한다.
최신 반입 허가·물량 수락·가격·여유 용량은 계속 null이다. 원본 웹페이지는 레포 밖에 보관하고
외부 모델에는 직접 작성한 사실 요약만 전달한다.

## 6. 완료 조건

- [x] 신규 사업장의 소재·공정·주소를 원문 대조하고 베일 반입 등 미확인 형태를 제외했다. 상세 투입 조건이 부족한 12연결은 AI 보류를 유지한다.
- [x] 문진 입력 목록 전체의 지원/보류를 검사하고 수도권 주요 재질 연결 전후 표를 생성했다.
- [x] 서울·경기 다중 출발지에서 같은 검토 후보 집합을 유지하고 좌표가 있는 후보의 거리를 정렬한다.
- [x] 금속 중간가공을 완료로 오인하지 않고 실제 산출물의 후속 조회가 동작한다.
- [x] 서버 단위·DB 검사, 실제 문진→공정 HTTP/웹 검사와 신규 공개 후보 Azure 검토를 기록했다.

[검증 결과 및 한계](../capital-region-coverage-20261116.md). 모든 소재·업체의 실반입이 검증됐다는 완료 표시는 아니다.

## 7. 미정 사항

현재 반입 규격·실제 회원 사업장 인증, 좌표 없는 신규 시설의 정확한 위치,
PE·PS 일반 베일의 국내 반입업체, PU·고무·페놀수지의 구체 공정은 근거 확보 여부에 따라 보류한다.
