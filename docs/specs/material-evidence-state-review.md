## 범위

PE 일반 베일, PET 플레이크, 수도권 알루미늄 음료캔의 공개 수행 사업장 자료를 추가 조사해 실제 가능한 공정 연결을 보강한다. 사업장·투입 형태·공정을 구분하며 판매/압축물 생산만으로 베일 수령을 단정하지 않는다. 현재 허가·가용 용량·이번 물량 수락은 미확인으로 유지한다. 분류 엔진, 외부 업체 연락, 운영 배포·병합은 범위 밖이다.

## 데이터·API

- 기존 공정 참조 JSON과 PostgreSQL 스냅샷에 동일한 변경을 반영한다. 출처·확인일·사실 요약·해시 방식·지원 레코드·주소·좌표 출처를 기록한다. 원문 전체나 사진은 레포에 재배포하지 않는다.
- 기존 API의 필드를 삭제·이름 변경·타입 변경하지 않는다. 업체의 공정 관련성과 실제 반입 승인을 구분한다.
- 현재 형태/실제 산출물 상태에 맞는 다음 공정만 제안하며, 웹 공정 탭은 현재 검토 응답의 공정 목록을 따른다. 사진만으로 분류·순도·향후 공정을 확정하지 않는다.
- 공개 근거 캐시와 물량·사진 캐시는 분리한다. 상태·사진·근거·모델 버전이 달라지면 관련 판정을 새로 검토한다. 동일 입력 재검토에서는 재사용 수와 실제 호출 수로 캐시를 확인한다.

## 완료 조건

- [x] 코드·재질·형태별 양성/음성 조회와 B 실제 산출물 후속 조회를 확인한다.
- [x] 보강 후보에 실제 Azure 검토·카카오 도로거리 검사를 수행한다.
- [x] 동일 입력 재검토 캐시 재사용과 상태 변경 시 새 판정을 실제 호출 수로 확인한다.
- [x] 웹에서 형태/현재 상태에 따라 공정 탭과 업체가 갱신되고 이전 상태 탭이 남지 않음을 확인한다.
- [x] 회귀 검사·근거/공백·변경 범위를 기록하고 해당 PR을 갱신한다.

## 구현 결과

시설 64곳·연결 132개. PE 일반 베일 1곳, PET 플레이크 3곳, 알루미늄캔 4곳이 공정 관련성 AI 검토를 통과했다. PE는 세부 산출물 형태를 추정하지 않는 `pe-recycled-resin` 상태를 추가했으며 자동 완료 상태로 사용하지 않는다. PS 일반 베일은 미확보다. 업체 없는 공정의 빈 탭을 제거했고 상태 변경 시 선택을 초기화한다. 상태 설명/사진의 선별·세척·건조 확인사항은 상단 탭에도 표시한다.

검증과 한계는 [실호출·웹 검증 기록](../material-evidence-state-validation-20261120.md), 호출 수는 [검증 요약](../verification/material-evidence-state-20261120.json)을 따른다. 문진 엔진과 기존 API 필드는 수정하지 않았다.

## 미정 사항

공개 자료가 확인되지 않은 업체 수와 현장 반입 한도는 미정이다. 숫자를 채우기 위한 연결을 하지 않는다. 문진 구조화 형태 출력은 T-180의 담당자 후속 작업이며 이 변경에서 문진 규칙을 수정하지 않는다.
