# R유형과 후보 근거 연결

상태: 확정. 2026-11-16 사용자의 R코드·UI·백엔드 전체 연결 요청에 따른 구현 명세.

## 범위

diagnosis가 별표 4의3의 코드별 재활용 유형과 사전 분석 조건을 출처·기준일과 함께 전달한다.
server는 로그인 기업 소유 문진 결과에서만 받아 후보 요청·물량·AI에 전달한다.
web은 유형·분석 필요 여부·출처와 실제 업체 허가 미확인을 구분해 표시한다.
현재 지원 소재의 일반 분류번호를 원문 대조하며 지정폐기물·범위 밖 결과를 일반 후보로 승격하지 않는다.

R-10은 후속 재활용 목적에 종속된다. 같은 코드가 사전 분석 해당/해당 없음 양쪽에 나타나면 둘 다 보존한다.
기존 확정 판정·Trace는 수정하지 않는다. 이전 인계 객체는 소유권 검사한 보충 조회로 현재 지원하는 법 버전을 대조한다.
B의 실제 산출물에 A의 분류/R유형을 자동 재사용하지 않는다. 업체 허가·계약 수락을 자동 확정하지 않는다.

## 계약

기존 필드 삭제·타입 변경 없이 handoff에 선택적 recycling 객체를 더한다.
대상 분류번호, table_listed/not_applicable/not_covered/out_of_date 상태, free/analysis/unmarked 그룹,
출처 URL·문서 버전·검사일·쪽·비고를 기록한다. 미지원/기준일 불일치면 유형은 비어 있다.
기존 확정 건은 diagnosis의 기업 인증된 기존 건 상세 API의 recycling 보충 응답으로 보충할 수 있다.
server treatment context와 물량에 출처를 함께 보관하고 candidate packet은 그룹을 보존한다.
클라이언트에서 보내는 임의 R유형으로 문진 결과를 덮어쓰지 않는다.

## 근거 검토

넷스파와 대한제강 원문을 대조하고 사업장·투입물·공정의 연결이 요약에서 손실되지 않게 한다.
AI는 공개 공정 사실과 이번 물량의 허가/수락을 구분한다. 특정 업체의 결과를 하드코딩하거나 성공할 때까지 재시도하지 않는다.
다른 사업장, 다른 재질·형태, 생산품 소개, 반입 제한 인용은 계속 차단한다.
