## 목적 / 범위

문진에서 포장재·폐어망·기타 수지·비철로 확정한 건에 빠진 세부 재질을 사용자가 확인한다.
기존 분류번호, handoff, 사업장 위치, AI 전체 후보 검토와 수신 기업 수락 흐름은 유지한다.
법적 분류 재판정, 사진으로 재질 확정, 혼합물을 단일 재질로 가정, 실시간 반입 승인은 제외한다.

## 요구사항

1. 분류번호와 원래 재질군의 허용 목록에 속하고 해당 코드의 공정 프로필이 있는 선택지만 제공한다.
2. 세부 재질 미선택·모름·목록 밖 값에는 후보를 제공하지 않는다. 기존 PP 등 구체적 문진 재질을 다른 재질로 바꾸지 못한다.
3. 현재 형태 선택은 세부 재질 변경 시 초기화한다. 고체 확인, 오염·지정폐기물 보류를 우회하지 못한다.
4. 확인값은 원문과 분리해 로트의 sender_confirmations와 initial에 보존한다. 이후 AI·인계는 같은 재질을 쓴다.
5. 비철 스크랩은 알루미늄 음료캔 공정으로 연결하지 않는다. 별도 공개 공정·시설 근거를 갖춘 경로만 추가한다.

## API / 데이터

기존 POST `/api/v1/diagnosis/cases/{id}/treatment/next-step`, `intake-reviews`,
`/api/v1/workflow/lots`에 optional `material_detail: string | null` 추가.
인증·기업 소유권·오류 계약은 유지한다(성공 200, 미인증 401, 미소유 404, 잘못된 형식 422).
응답에 `available_materials`, `selected_material` 추가. 새 DB 테이블 없음.
기존 JSON sender_confirmations에 material_detail 저장. handoff는 수정하지 않는다.

## 완료 조건

- [x] 포장재 PP·PE·PET, 폐어망 PA6, 기타 수지 SAN·PA66·PCABS, 비철 알루미늄 스크랩에서 코드 유지·후보 연결
- [x] 미선택·모름·재질 위조·코드 충돌·액상·지정폐기물에서 잘못된 후보 차단
- [x] 등록·재조회 시 세부 재질 보존, 후보 AI 전달값 일치
- [x] 실제 문진 API→경로→브라우저 선택과 실제 Azure 후보 검토 재확인

## 미정 / 한계

미확인 혼합물, 미지원 비철 종류, 업체 반입 조건·허가는 확인 필요로 남긴다.
공개 자료가 없는 연결은 추정으로 승인하지 않는다.
