# 업체 후보의 도로거리 비교

## 2026-11-17 사업장 위치 보강

누락된 30곳은 업체가 공개한 사업장 주소 또는 공공 명부의 사업장 주소를 건물 단위 지도와 대조해 좌표를 보강한다. 본사·시군 중심점·인근 업체 좌표를 대입하지 않는다. 주소의 건물 대표점이며 차량 출입구 실측 좌표는 아니다. 도로 스냅 500m 제한은 유지한다.

각 보강 좌표는 위치 출처 ID·확인일·원문 해시와 연결하고 기존 `location_source_url`로 전달한다. 위치 근거는 처리능력·허가·반입 승인 근거로 승격하지 않는다. 참조 스냅샷 갱신 뒤 A/B 출발점의 전 재질 후보와 철스크랩 지도 표시를 재검사한다.

2026-11-17 사용자 요청: 최신 통합 PP 시나리오를 재검사하면서 가능하면 직선거리 대신 도로 경로 API를 적용한다. 기존 후보 생성·AI 검토·수락·QR 계약은 유지한다.

- 카카오모빌리티 자동차 길찾기 API로 현재 보유 기업 좌표→각 업체 좌표를 조회한다. 사업장 이름·계정·폐기물·사진은 전송하지 않는다. 인증된 문진 경로 조회와 물량 후보 검토에 적용하며 공개 레거시 조회에는 유료 호출을 추가하지 않는다.
- `KAKAO_MOBILITY_REST_API_KEY`가 설정된 경우에만 호출한다. 키는 서버 환경변수이며 웹 번들에 넣지 않는다.
- 전체 후보를 업체 단위로 중복 제거해 최대 3곳씩 동시에 조회한다. 호출별 6초·전체 20초 제한이며 자동 재시도하지 않는다. 먼저 직선 상위 5곳만 고르는 방식은 사용하지 않는다.
- 성공한 거리만 `road_distance_km`, `road_duration_seconds`에 기록한다. 기존 `straight_line_distance_km`는 덮어쓰지 않는다. 미설정·좌표 없음·외부 오류·경로 없음은 구분한다.
- 도로거리가 하나라도 확인되면 확인된 업체끼리 거리순으로 최대 5곳을 지도에 표시한다. 나머지 후보는 목록·AI 검토에서 유지한다. 일부만 확인되면 전체 업체 중 최단거리라고 표현하지 않는다. 모두 미확인이면 직선거리임을 명시한다.
- A→B뿐 아니라 B→C도 현재 보유 기업의 위치를 사용한다. 거리와 조회 시각은 후보 검토에 저장한다. 같은 조건의 완료 검토는 캐시를 사용한다. 키 활성화 여부·사업장·사진·산출물·답변·참조자료 버전이 바뀌면 다시 계산한다. 실시간 교통 갱신용이 아니다.
- 기본 자동차 경로 참고값이며 화물차 높이·중량·위험물 통행 제한, 실제 운송비·수락 여부를 판정하지 않는다.

완료 조건: 실제 API 규격에 맞춘 요청, 모든 후보·중복 제거·부분 실패·401/429/시간초과·잘못된 응답·미설정 검사, 도로/직선 혼합 순위 방지, A/B 위치 전달 회귀 검사. 키 미설정 시 모의 응답 검증과 실호출 결과를 구분해 보고한다.

공식 규격: https://developers.kakaomobility.com/guide/navi-api/directions.html

## 통합 시험에서 확인한 부분 재시도

14곳 중 2곳의 모델 응답이 시간초과로 미완료가 됐다. 동일한 물량·사진·단계·문진/R유형·참조자료·추가답변·사업장 버전에서는 검토가 끝난 후보 결과를 유지하고 미완료 후보만 다시 호출한다. 사진/산출물/답변 변경은 기존처럼 검토를 무효화한다. 미완료 결과는 수락 근거로 사용하지 않으며, 후보 전체 키 집합이 갖춰져야 전체 완료 캐시로 인정한다.

재시도는 사용자가 누를 때 미완료 후보를 하나씩, 최대 3개 동시 호출한다. 전체 175초가 지나도 이미 끝난 결과는 보존하고 나머지는 미완료로 둔다. 실제 두 후보 개별 재시도 후 14/14 완료, 성공한 기존 12개 결과 보존을 확인했다. [최신 웹 시험 결과](../final-integrated-e2e-20261117.md)

## 키 없는 로컬 시연용 OSRM

사용자 요청에 따라 OSRM_DEMO_ENABLED=true인 로컬 환경에서 카카오 키가 없으면 FOSSGIS OSRM 자동차 Table API를 사용한다. 기본값은 false. 전체 좌표 후보를 40곳씩 묶고 초당 1회 이하·24시간 메모리 캐시·제한된 캐시 크기로 공개 서버 부하를 제한한다. 공개 서버 사용은 단일 워커의 소규모 시연만 허용하며 운영은 자체 호스팅/계약 서비스를 사용한다.

좌표만 외부 전송하고 기업명·사진·폐기물 정보는 보내지 않는다. 도로 스냅이 500m를 넘거나 경로가 없으면 미확인으로 둔다. OSRM은 최단시간 경로의 거리이며 최단거리 보장이 아니다. 지도에 OSRM/FOSSGIS와 OSM 출처·지도 수정 링크를 표시한다. 실제 국내 좌표 실호출·상위5·부분 실패·캐시 검증 후 로컬 화면에 반영한다.

2026-11-17 후속: OSRM 공개 자동차 Table API 실호출로 화성 출발 14후보 중 좌표 있는 9곳의 거리를 확인했다. 상위5는 새롬16.3/NPC18.9/일신43.9/유원43.9/중일44.8km. 좌표 없는5곳은 목록 유지·순위 제외. 서버509/웹66 검사 통과. OSRM은 최단시간 경로 거리이며 최단거리·화물차 통행을 보장하지 않는다. 로컬 시연 옵션이며 운영은 별도 호스팅 필요. API 키 없이 실제 도로거리 확인을 완료했으며 이전 보고서의 '도로거리 전부 미검증'은 카카오에만 해당한다.
