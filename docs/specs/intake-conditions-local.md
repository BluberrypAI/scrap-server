# 업체별 반입 확인과 조건부 수락

상태: 사용자 요청으로 확정 — 2026-11-14 구현·검증 후 PR 요청. 공개 배포·실제 기업 연락은 하지 않음.

관련 기획: 사용자의 업체별 반입조건 수집, 후보별 문진, 조건부 수락, PP 외 소재 연결 요청.

## 범위
- 공개 자료의 사업장별 투입 예시·명시적 제한을 출처·확인일과 저장한다. 예시는 독점적 허용 규격으로 사용하지 않는다.
- PP, PE 필름, 확인한 알루미늄 음료캔을 연결한다. PET병은 공정 자료와 일치하는 확정 번호(51-03-07)에만 연결하며, 현재 일반 PET 문진 결과(51-03-01)는 계속 보류한다. 실제 산출물 상태로 후속 공정을 조회한다.
- 전국 명부를 현재 공정 탐색에 연결하고 모든 일치 건을 페이지로 조회한다. 명부 일치·설비 키워드는 검증된 처리능력이 아니다.
- 후보별 답변과 출처를 단계별 저장한다. 모름·위험 응답은 수신기업 검토로 넘긴다.
- 수신기업이 조건을 제시 → 발송기업이 자료 제출 → 수신기업이 해소 확인 후 최종 수락한다. 그 전 QR 발급 금지.
- 제외: 실제 기업을 가장한 계정 연결, 자동 허가 승인, 임의 반입 허용치, 지원하지 않는 분류번호 추정, 실제 기업 연락.

## API (추가)
인증 및 해당 로트 참여 권한 필요. 쓰기는 revision 충돌 검사.
- POST /api/v1/workflow/lots/{id}/intake-answers: 현재 보유 기업의 후보별 문진 답변. 200/403/404/409/422.
- POST /api/v1/workflow/lots/{id}/directory: 현재 단계의 전국 명부 조회, 페이지·출처·미확인 조건 반환. 200/403/404/409/422.
- POST /api/v1/workflow/lots/{id}/directory-inquiries: 현재 명부 페이지의 업체·질문 답변 저장. 단계별 최대 100곳. 저장은 인수 요청·공정능력 인증이 아님.
- POST /api/v1/workflow/offers/{id}/conditions: 수신기업의 조건부 수락 조건 등록. 200/403/404/409/422.
- POST /api/v1/workflow/offers/{id}/condition-responses: 발송기업 자료 제출. 200/403/404/409/422.
- 기존 decision에 resolved_condition_ids 선택 필드 추가. 모든 조건에 답변이 있고 수신기업이 확인한 경우만 최종 수락.

## 저장
기존 WorkflowLot.data에 단계/후보별 intake_answers와 directory_inquiries, WorkflowOffer.data에 questionnaire snapshot, conditions, condition_responses, decision 기록. 새 테이블 없음. 기존 키/응답 호환 유지.
응답은 자기신고이며 검사·허가 인증으로 승격하지 않는다. 다음 단계에 전 단계 답변을 재사용하지 않는다.
AI 요청에 질문과 답변을 함께 전달한다. 수정하면 이전 AI 결과를 무효화하며 공정 참조·반입조건 자료의 체크섬이 바뀌어도 재검토한다. 현재 질문만 유지해 AI 입력을 제한한다. 로그·보관 정책은 기존 업무 기록 정책을 따르며 신규 자동 삭제 주기는 정하지 않았다.

## 미정
실제 기업의 비공개 반입 한도·계약 단가·잔여 용량 및 등록계정 인증 자료는 미확보. 전국 명부는 미확인 탐색 대상이며 가입·사업장 연결이 없는 업체로 실제 인수 요청을 보내지 않는다.
