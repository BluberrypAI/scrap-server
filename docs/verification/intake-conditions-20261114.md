# 반입조건·다중 소재 검증 기록 — 2026-11-14

## 사용자에게 달라지는 점

1. 다음 공정 후보를 열면 업체가 공개한 투입 예시와 출처를 볼 수 있다.
2. 오염·혼합·포장·수분·반출 일정과 업체별 확인 질문에 답한다. 모르면 모름으로 남긴다.
3. 답변은 해당 단계·업체에 저장하고 기존 AI 검토를 지운다. 재검토하면 질문과 답변도 Azure 모델이 함께 본다.
4. B는 바로 수락하거나 조건을 제시할 수 있다. 조건부 상태에서는 QR이 없다.
5. A가 조건별 자료 번호·설명을 보내고 B가 모든 조건을 확인해야 최종 수락된다. 이후 QR 입고·실제 산출물·다음 업체 조회로 이어진다.
6. 전국 명부의 다른 업체도 페이지별로 조회하고 질문 답변을 저장할 수 있다. 근거·수신계정이 없는 명부 행은 실제 인수 요청 대상이 되지 않는다.

## 공개 근거

2026-11-14 확인. 다음 링크의 사실을 짧게 정리해 자체 요약으로 저장했다. 원문 전체를 복사하지 않았다.

- [베올리아 화성](https://www.veolia.kr/ko/plastiloop-hwaseong): 독산 PP 플레이크·베일, DSPL 재생 PP 펠렛 투입 예시.
- [중앙이엔비](https://www.jungangenb.com/): PE·PP 상담, 지정폐기물 제외 및 물량·일정 확인. 제외 조건은 일반 수락 버튼으로 우회할 수 없다.
- [삼양패키징](https://www.samyangpackaging.com/kr/business/pet-recycling): PET병 선별·분쇄·세척·건조·금속 분리. 같은 사업장 내부 공정을 불필요하게 여러 운송 구간으로 나누지 않았다.
- [수퍼빈 공장](https://superbin.co.kr/business/factory): 화성의 자체 회수 PET병 → 플레이크, 순창의 플레이크 → 펠렛. 외부 공급자 물량 수용은 확인되지 않았다.
- [Novelis 울산 재활용센터](https://investors.novelis.com/news-events/press-releases/detail/1390/novelis-opens-ulsan-aluminum-recycling-center): 캔·자동차·산업 알루미늄 스크랩 처리 공개 사례. 합금별 허용 한도는 미확보.
- [전국 폐기물 처리업체 표준데이터](https://www.data.go.kr/data/15114147/standard.do): 명부 코드·설비·기준일. 개별 공정 수행능력·현재 인수 가능 여부를 보장하지 않는다.

## 아직 확보되지 않은 것

- 업체별 오염·수분·순도 수치 규격, 최소 물량, 현재 용량, 계약 단가, 실시간 허가 검증, 실제 담당자 계정 인증.
- 9개 역할 추정 연결을 공정 수행 사실로 승격할 자료. 이번에도 추정 상태를 유지했다.
- 일반 PET 문진과 PET병 공정 번호의 연결 정리. 금속캔 번호만으로 알루미늄이라고 확정하지 않고 별도 형태 확인을 요구한다.
- 철·구리·기타 폐기물의 완성된 문진→인계 경로. 종이 공정 참조가 있더라도 전체 흐름 지원과 다르다.

즉 **명부 전체 조회와 확인 작업의 저장은 연결했지만, 9,604행 모두의 반입능력 검증을 끝낸 것은 아니다.** 이 구분이 데이터와 UI에 그대로 남는다.
