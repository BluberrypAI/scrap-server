# PE·PS 베일 / EPS 감용 추가 확인

## 여기서 근거란?

**그 사업장이 어떤 원료·형태를 받아 무슨 공정을 하는지 확인할 자료**다. 회사 공식 공정
페이지, 공시, 공공 사업장 자료를 사용한다. URL·본문 위치·확인일·요약과 지원하는 연결을
저장한다. 업체 이름이나 분류코드만 있는 전국 명부는 조사 출발점이다.

공개 자료는 `현재 우리 물량을 받겠다`는 승인이 아니다. 로트의 상태·사진, 최신 허가,
오염·수분·규격·물량 조건과 수신 기업의 수락은 따로 확인한다. 베일을 **만들거나 파는**
업체를 베일을 **받아 가공하는** 업체로 바꾸지 않는다. AI도 이 구분과 누락을 검토한다.

## 새로 연결한 EPS 사업장

[한울메탈 공식 공정](https://hanul-metal.com/process)의 EPS 라인과 사업장 주소를 확인했다.
신규 `hanul-ulju`를 **EPS 스티로폼 → 분쇄·감용 → 감용물**에 연결했다.

- 신규 공정 `eps-foam-volume-reduce`, 산출 상태 `eps-reduced`.
- 원문이 인고트 규격까지 말하지 않으므로 기존 `eps-ingot`과 구분한다.
- A→B 후보 조회·전체 AI 검토·수신 수락·QR 입고에 같은 계약을 적용한다.
- B가 `eps-reduced`를 기록하면 완료·인고트 업체 연결은 보류한다. 다른 산출물인
  인고트를 기록하면 기존 `review_required`로 남는다. 현재 이 보류를 풀 현장 증빙 검수
  절차는 별도 필요하다. 이 연결만으로 EPS A→B→C가 끝까지 완료됐다고 말하지 않는다.
- 원래부터 인고트로 확인된 물량의 에코피에스 후보 경로는 유지한다.
- 기존 9,604행 명부의 동일 사업장 행·좌표는 확보하지 못했다. 좌표·현행 허가·가격·
  여유 용량은 null이다. 허용보관량을 처리능력으로 바꾸지 않는다.

직접 파일 다운로드는 403이었다. 웹 리더로 확인한 사실만 요약하고 해시는
`curator-record-not-original-page`로 명시했다. 원본 파일 해시로 표기하지 않았다.

## PE·PS 베일: 발견한 단서와 연결하지 않은 이유

| HRM | [공식 매입 안내](https://hrmcorp.co.kr/en/trading/plastics)에 LDPE 필름·HDPE 베일 매입 명시 | 무역 매입이다. [청주 MRF](https://hrmcorp.co.kr/en/cheongju-mrf)는 선별·압축·출하를 안내하며 베일 해체·가공 수령 사업장이라고 하지 않는다. **매입 문의 단서는 확보, 처리시설 연결은 보류** |
| 해동자원 경산 | [CAPA 공장 정보](https://capa.ai/factory/87030/%28%EC%A3%BC%29%ED%95%B4%EB%8F%99%EC%9E%90%EC%9B%90)에 PE·PP·PET 압축품 원료 단서 | 자동 작성된 2차 정보다. [경산시 기업 현황](https://www.data.go.kr/data/15100835/fileData.do)은 기본 기업 정보이고 투입 형태 확인 자료가 아니다. 원료 열이 있는 공공 원본 또는 회사 공정 자료 필요 |
| 대영 논산 | 공장 디렉터리의 압축품→재생 PP·PE 단서 | 상월로 216-20 사업장 원료·공정 원문 미확보. 회사명이 같은 다른 사업장과 합치지 않음 |
| GB World Trade | 과거 업체 매입 공고의 PS 베일 단서. [현재 회사 제품 소개](https://www.gbworldtradecoltd.com/plastic-recycling.php)는 수출입 중심 | [회사 공장 소개](https://gbec21.en.ec21.com/company_factories.html)의 재활용 공장은 파키스탄. 한국 창고를 국내 PS 베일 처리공장으로 연결하지 않음 |
| 명진자원 | [EPS 처리 특허](https://patents.google.com/patent/KR102866690B1/en) | 특허는 현재 국내 사업장의 설치·운영·외부 반입을 증명하지 않음 |
| 전주화학·벼리산업 | [전주시 2018년 안내](https://www.jeonju.go.kr/planweb/board/view.9is?boardUid=ff8080818990c349018b1dbaa78e4b41&contentUid=ff8080818990c349018b041a87373953&dataUid=9be517a762e870eb01638bb6ffec1459) | 과거 수거·재활용 안내. 현행 사업장과 감용 라인·산출 형태를 확인하기 전 연결 보류 |

해동**자원**과 같은 주소의 해동**산업**은 구분했다. 앞선 보류 기록의 해동산업 표기를
그대로 동일 기업의 근거로 사용하지 않는다. HRM의 새로운 매입 안내는 이전 제품 판매
단서보다 구체적이지만, 국내 가공 사업장 확인을 대신하지 않는다.

현재 PE 베일 두 코드 조합·PS 베일 한 조합은 여전히 `no_route`다. 해외 일반 공정 설명은
남아 있어 화면에서 필요한 단계를 볼 수 있고, 지역별 공개 검색으로 추가 조사가 가능하다.
검색이 실패한 경우와 검색했지만 업체를 찾지 못한 경우도 구분한다.

## 최신 검증

참조 전체는 **50개 사업장·59개 공정·105개 연결**이다. 역할 확인 필요 14개는 유지한다.
자동 시험·실제 서버 조회·Azure 검토 결과는 [경로 검증 기록](../route-coverage-20261115.md)의
마지막 추가 검증 절에 기록한다. 이전 라운드의 수치를 이번 결과로 덮어쓰지 않는다.
