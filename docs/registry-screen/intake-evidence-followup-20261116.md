# 추가 근거 12개와 PE·PS 베일 재조사

확인일: 2026-11-16. 이 문서의 업체는 공개 자료 조사 후보다.
이번 물량의 인수 허가·가격·가동 여부는 업체의 최종 수락과 별도로 확인해야 한다.

## 무엇이 더 확인됐나

- **성원산업 화성 공장 추가**: LDPE 폐필름 매입부터 선별·이중 압출·펠릿 생산까지 같은 공식 홈페이지에서 확인했다. PE 필름에만 연결했다. HDPE 경질·압축 베일·자체 열분해로 확대하지 않았다.
- **한국철강 창원 보강**: 제품 소개에 없던 철스크랩 구매·전기로 투입 설명을 2026 반기보고서에서 확보했다. 절단 치수나 현재 반입 승인이 확인됐다는 뜻은 아니다.
- **인천리사이클링 보강**: 기존 짧은 요약에서 빠진 원료 수거·운반·파봉·재질별 광학선별 순서를 추가했다. 수원시의회 보고서로 2024년 미선별 혼합 플라스틱 계약도 대조했다.
- **기은알에스 보강**: 정부 현장방문 자료로 광학선별 수행을 추가 확인했다. 같은 영상에 나온 알엠·수퍼빈의 세척·펠릿 공정은 이 업체에 붙이지 않았다.

## 12개 연결에서 여전히 확인할 부분

아래는 원문 대조 결과다. 재실행한 모델에서는 한국철강 1개가 근거 확인, 나머지 11개는 추가 자료 필요였다.
11개 모두 투입 형태가 부족하며 환경수지는 공정 근거도, 기은 PP·PS는 출하품과 투입 원료의 구분도 필요하다.
모델 상태와 사유는 [검증 JSON](../intake-evidence-followup-validation-20261116.json)에 함께 기록한다.

| 연결 | 추가 확인 | 남은 확인 |
| --- | --- | --- |
| 창우RS 화성 → PE 선별·압축 | 원료 입고·계근·검수·선별·압축 | PE 경질의 구체 투입 사례·규격 |
| 창우RS 화성 → PET 선별·압축 | PET 회수품 취급 | PET병 투입 형태·로트 규격 |
| 환경수지 안성 → PE 분쇄 | 공장등록 생산품·과거 명부 설비 대조 | 현재 사업장 공정 설명·투입 형태. 자동 생성 기업소개는 근거로 승격하지 않음 |
| 인천리사이클링 → PE 선별·압축 | 원료 투입부터 PE 광학선별·압축까지 | 경질 형태의 외부 사업장 로트 |
| 인천리사이클링 → PET 선별·압축 | PET 광학선별 공정 | PET병 투입 형태·로트 규격 |
| 인천리사이클링 → PP 선별·압축 | PP 광학선별 공정 | 경질 형태의 외부 사업장 로트 |
| 인천리사이클링 → PS 선별·압축 | PS 광학선별 공정 | 경질 형태의 외부 사업장 로트 |
| 기은알에스 → PE 선별·압축 | 정부가 광학선별 현장 확인 | PE 경질 투입 형태·규격 |
| 기은알에스 → PET 선별·압축 | 정부가 선별 현장 확인 | PET병 투입 형태·규격 |
| 기은알에스 → PP 선별·압축 | 정부가 선별 현장 확인 | PP 경질 투입 형태·규격 |
| 기은알에스 → PS 선별·압축 | 정부가 선별 현장 확인 | PS 경질 투입 형태·규격. 압축 PS는 출하품 |
| 한국철강 창원 → 가공 철스크랩 전기로 | 2026 반기보고서의 철스크랩 구매·전기로 투입, 창원 생산 | 실제 절단 치수·등급·합금·오염 한도·로트 수탁 |

`PE film-bale`의 기존 디에이치원 성주지점 경로는 일반 PE 경질 베일과 다르다.
PS 경질 베일은 EPS 스티로폼 감용 인고트와도 다르다. 서로 대체하지 않았다.
