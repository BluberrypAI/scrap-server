# 기존 근거 부족 252회의 재검토

## 자료가 있어도 AI에 못 보낸 경우

현재 참조에서 전송 가능한 출처가 하나도 없는 사업장: 새롬이엔지 화성 제2공장.
이는 회사 자료가 세상에 없다는 뜻이 아닙니다. 전송 제한을 자동 해제하지 않습니다. 행별 JSON의 eligible_source_ids / withheld_source_ids로 구분할 수 있습니다.
