# 반입 근거 보강 후 연결 검사

2026-11-16. 로컬 `localhost:5178 → server:8000 → diagnosis:8030 / route:8010`에서
합성 기업 입력과 공개 사업장 요약으로 실행했다. 실제 반입·배송이나 독립 전문가 정확도 평가는 아니다.

새 연결은 성원산업 화성 공장의 **LDPE 필름 → 이중 압출 → 펠릿**이다.
자료에 없는 세척 공정을 붙이지 않았고, PE 경질·일반 베일·압축 필름·파쇄품·펠릿 입력에는 노출하지 않는다.
원문에서 확인된 범위와 베일 조사에서 제외한 단서는 [업체별 재조사](registry-screen/intake-evidence-followup-20261116.md)에 기록했다.

## 실제 실행한 검사

- 실제 버튼 문진 18선택지: 12개 번호를 원래 값대로 보존. 세부 재질·형태 56조합 중 53조합에 후보가 있다.
- Edge 브라우저 59검사: 형태 선택, 후보 표시, R유형·출처 표시, 빈 후보·미지원 안내 확인.
- 추가 실제 웹 버튼 검사: PE 필름 선택 → '업체 공개 근거 AI 검토' 클릭 → 실제 Azure 응답 → 17개 카드에 결과 17개 표시(확인 5·부족 12). R유형 보존·자동 승인 없음 확인. 아래 142응답 집계와 별도 검사다.
- HTTP 212조회: 지원 소재 64공정·124연결 도달. 나머지 5공정·5연결은 문진 범위 밖 종이 자료다.
- 서울·화성·파주·안성·남양주 합성 출발점: 위치가 달라도 전체 AI 검토 후보는 유지하고, 확인된 좌표만 직선거리 Top 5로 정렬.
- SQLite 487개, 별도 PostgreSQL 17 시험 DB 487개 통과. Ruff check / format 통과.
- Route 558개, 하위 검사 24개 통과. 환경 의존 검사 72개는 생략했다.

Azure 검사는 실제 확정 문진의 R유형·출처를 전달한 첫 공정과 실제 산출물을 가정한 후속 공정을 구분한다.
전체 형태 화면은 전수 검사하되, AI는 모든 고유 연결을 포함하는 대표 입력으로 재검토했다.
모든 후보의 결과 키가 요청과 같고 `dispatch_approved=false`인지 검사했다.
최종 집계와 기존 보류 12개 각각의 상태는 [검증 JSON](intake-evidence-followup-validation-20261116.json)에 있다.

### Azure 실제 검토 결과

- 확정 문진 첫 공정 30개 대표 입력 + 후속 산출물 6개 입력, 총 142개 후보 응답.
- 지원 소재의 고유 공정-사업장 연결 124개를 모두 포함했다. 모든 형태·업체 조합을 AI로 전수 검사한 것은 아니다.
- 142개 응답 중 공개 근거 확인 39회, 추가 근거 필요 103회. 최종 호출 불가·후보 누락·자동 인수 승인 0회.
- 기존 보류 12개 중 **한국철강 창원 가공 철스크랩 → 제강 1개**가 공개 근거 확인으로 바뀌었다. 나머지 11개는 보류다.
- 보류 11개 모두 구체적인 투입 형태 근거가 부족하다. 환경수지는 공정 근거도, 기은 PP·PS는 출하품과 투입 원료 구분도 더 필요하다.
- 신규 성원산업 화성 LDPE 필름 연결은 공개 근거 확인 응답을 받았다.

같은 연결도 입력 형태·증빙에 따라 결과가 달라진다. 고유 연결별 마지막 응답 집계는 33개 확인·91개 부족이며,
이는 고정된 업체 등급이나 현장 정확도가 아니다. 허가·반입 규격·현재 수용과 실제 인수는 여전히 업체 확인 대상이다.

## 장애도 별도로 기록

처음 병렬 검토에서 Azure 호출 한도 오류가 발생해 실행을 중단했다.
이 결과를 근거 부족으로 집계하지 않고, 문진 완료 후 순차 호출과 간격을 두어 재검사했다.
공급자 호출 불가가 남은 입력만 다시 실행했다. 원본 최초 결과는 로컬 검증 기록에 보존했다.

Route는 공급자 요청 거절·주소 없음·서버 오류·시간 초과를 허용된 사유 코드로만 로그에 남기도록 보강했다.
원문 응답·토큰·기업 이름을 로그에 쓰지 않는다. 통과 기준이나 자동 승인 정책은 바꾸지 않았다.

## 팀 적용

브라우저 AI 버튼 검사는 앞선 `audit_diagnosis_routes.py`로 생성한 합성 문진 JSON을 사용한다.
로컬 서버와 Edge가 실행 가능한 환경에서만 아래 명령을 실행한다. 실제 Azure 호출을 포함한다.

```bash
uv run --with playwright --project backend python scripts/audit_browser_ai.py --input /path/to/diagnosis.json --output /path/to/browser-ai.json
```

server PR #47과 route PR #61을 적용하고 서버·route를 재빌드한다.
같은 서버 이미지로 `docker compose run --rm server-seed`를 실행한다.
기존 PostgreSQL 볼륨의 주 버전은 그대로 유지한다. 이 변경에는 새 DB 마이그레이션이 없다.

PE·PS 일반 베일은 아직 국내 투입 사업장의 원문이 부족하다. 기존 압축 필름과 EPS 인고트를 대신 연결하지 않았다.
PU·고무·페놀도 지원 완료로 바꾸지 않았다. 공정 근거 확인과 현재 물량의 수락은 별개다.
