## 먼저 결론

PP·PET·PE는 문진 → 후보 조회 → 실제 Azure 검토 → 별도 기업의 수락 → QR 입고 → 산출물 기록 → 완료까지 연결된다. 각 소재에서 A→B로 끝나는 경우와 A→B→C를 모두 시험했다. 알루미늄은 **사용 후 음료캔**의 A→B 완료를 시험했다.

전국 모든 폐기물·업체를 검증했다는 뜻은 아니다. 고철·비철 일반 스크랩은 문진 번호까지 나오지만 공정 연결 자료가 없다. PE·PS 압축 베일은 국내 반입 업체의 공개 근거가 부족하다.

기업 계정·물량·입고·산출물은 **합성 시험 데이터**다. 실제 업체가 수락했거나 허가·반입 조건을 검증한 결과가 아니다. HTTP 시나리오는 별도 로그인 세션으로 실행했고, 브라우저에서는 지도·위치 저장·경로 선택·완료 이력·빈 결과 안내를 확인했다. 7개 전 과정을 모두 브라우저로 수동 클릭한 시험은 아니다.

## 실제 연결 시험 7건

아래 업체명은 공개 참조 사업장이고, 수신 계정 연결은 로컬의 `synthetic` 설정이다.

| 시험 | 고른 경로 | 결과 |
| --- | --- | --- |
| PP 바로 완료 | A의 파쇄품 → 독산 화성 → 펠렛 | 완료 |
| PP 중간 처리 | A → 새롬 화성 제2공장 → 파쇄품 → 독산 화성 → 펠렛 | 완료 |
| PET 바로 완료 | A의 병 → 유일 부산 → 플레이크 | 완료 |
| PET 중간 처리 | A → HRM 청주 → 베일 → 유일 부산 → 플레이크 | 완료 |
| PE 바로 완료 | A의 파쇄품 → 그린폴 천안 → 펠렛 | 완료 |
| PE 중간 처리 | A → 새롬 화성 제2공장 → 파쇄품 → 그린폴 천안 → 펠렛 | 완료 |
| 알루미늄 캔 | A → 노벨리스 영주 → 판재 | 완료 |

각 인계에서 수락 전 QR 발급, 다른 기업의 QR 입고, 같은 QR 재사용, 산출물 입력 전 다음 업체 조회를 차단했다. 중간 산출물을 최종 완료 처리하는 요청도 차단했다. A·B·C가 서버에서 같은 완료 결과를 조회했다. B→C의 거리 기준은 A가 아닌 현재 담당 B의 사업장이다.

초기 시험 스크립트의 오류도 별도로 남겼다. PP 두 시험이 같은 문진 건을 재사용해 충돌한 것은 별도 문진으로 재시험했다. PE에 PP 업체를 고정 지정한 시험은 해당 업체가 반환되지 않아 중단됐고, 실제 PE 후보인 그린폴로 이어서 완료했다. 엔진에 없는 업체를 끼워 넣지 않았다.

## 이번에 고친 것

1. **회사 위치 저장**: 가입·기업 정보 수정에서 지도에 사업장 위치를 선택한다. 주소만 바꾸면 기존 좌표를 지운다. 새로고침 후에도 좌표가 남는다.
2. **거리순 Top 5**: 좌표가 있는 서로 다른 업체를 최대 5곳 우선 표시한다. 나머지·좌표 없는 업체는 펼쳐 볼 수 있다. AI는 조회된 후보 전부를 검토한다.
3. **위치 변경 후 재검토**: 기업 정보 버전이 바뀌면 이전 후보 캐시를 재사용하지 않는다. AI 호출 중 위치가 바뀌어도 오래된 결과를 저장하지 않는다.
4. **지도 토큰 없는 경우**: MapLibre와 OpenStreetMap으로 표시한다. 기존 Mapbox의 토큰 없는 실행 오류를 고쳤다.
5. **금속캔 문진 연결**: 문진에 고체 여부가 없는 경우 사용자에게 확인받는다. 분류번호만 보고 고체로 추정하지 않고, 기존 액체 응답을 덮어쓰지 않는다.
6. **빈 경로 안내**: 미지원·자료 부족·검토 보류·조회 오류·최종 상태를 구분하고 재조회/문진 확인을 제공한다.
7. **기업 등록 표시**: 사업장 정보 저장을 실제 기업 인증으로 오해하지 않도록 `인증 완료` 대신 `정보 등록됨`으로 표시한다.
8. **테스트 환경 분리**: 단위 테스트가 compose의 실제 엔진 URL·토큰을 물려받지 않게 했다. 실제 Azure 시험은 별도 스크립트로 수행한다.

거리에는 아직 지도 도로 API를 쓰지 않는다. 화면에 **직선거리**라고 명시한다. 좌표가 있는 23곳 안에서의 거리 비교이며 전국 모든 업체 중 가장 가까운 5곳이라는 뜻이 아니다.

같은 PE 경질 입력에 화성·부산·광주 좌표를 각각 적용한 HTTP 시험에서도 Top 5가 달라졌다. 첫 후보는 각각 새롬 화성(6.8km), 에코플러스 영주(183.8km), 영신 나주(24.7km)였다. 부산에서조차 가까운 업체가 나오지 않는 것은 현재 검증 자료·좌표의 지역별 공백이며, 거리 계산으로 해결되는 문제가 아니다.

## 전수 조회와 Azure 결과

- 실제 Docker 서버·PostgreSQL에 **176개 공정 조회**: 후보 반환 118, 근거 없는 경로 11, 최종 상태 47. 이 176건은 초기 입력과 합성 산출물 탐색을 합친 수다. 176개 실물 인계를 뜻하지 않는다.
- 도달 가능한 **97개 연결 전부**를 29개 입력 묶음으로 Azure에 전달했다. 중복 포함 114개 검토 결과를 확인했고 누락·모델 연결 실패는 없었다.
- 연결별 관찰 결과: 14개는 `reviewed`만, 82개는 `needs_evidence`만 나왔다. `youngshin-naju--pe-scrap-to-pellet` 1개는 입력 조합에 따라 두 상태가 모두 나왔다. 상태가 다르면 보수적으로 추가 확인한다.
- `reviewed`는 AI 검토가 이뤄졌다는 뜻이며 허가 승인·반입 가능 판정이 아니다. 모든 검토의 `dispatch_approved`는 false다. 업체가 최종 수락한다.
- 법적 정답률, 사진 판독 정확도, 실제 현장 수율·순도, 모든 조건부 수락 조합을 이번 시험만으로 평가하지 않았다.
